# R4c2 本地验收

[规格](../superpowers/specs/2026-10-13-r4c2-vehicle-plan-evidence-design.md)、[API](../api/VEHICLE_PLAN_EVIDENCE.md)、[执行记录](../progress/R4C2_VEHICLE_PLAN_EVIDENCE_EXECUTION.md)。

1. 车主生成方案，选择本人车辆，主动读取本车证据：六指标保留本人来源、日期、方法和版本，缺失/来源删除显示未知；请求不包含问题或任何第三方调用。
2. 无有效车型、不存在精确规则时UNKNOWN；相同动力类型但另一车型不继承规则。NOT_APPLICABLE阻止方案页继续选择，APPLICABLE仅声明有来源规则，UNKNOWN需要人工核对。无本车选择保留问题目录流程。
3. 同款摘要只展示当前有效授权和获批来源、当前精确车型，最多20；没有样本/关闭展示为空；翻页入口带入当前车辆选择，不携带私有档案。
4. 目录运营从标准库进入规则页，输入有效项目/精确车型号、读取当前版本、录入来源，明确确认后发布或撤销；撤销保留版本和审计。can_review单独不能维护。
5. 规则并发/旧版本409要求重新读取；网络未知结果以同body/同key重试。旧成功响应不复活规则，UI随后GET；审计失败回滚规则和幂等记录。停用目录/撤销权限也禁止历史重放。
6. 编辑问题/项目、生成新方案、换车、切换账号、隐藏清空证据并忽略晚响应；隐藏规则页或重读期间换账号不会把旧结果显示给新账号。

自动验证使用真实MySQL + HTTP安全链 + 小程序离线协议/生命周期替身，不代表真机或正式渠道。实际命令、数量与已修正失败见执行记录，最终完整CI见PR正文。来源真实性/车辆识别真实性尚未验证；未启用任何正式短信、微信身份或资金渠道；不合并或发布。
