日期：2026-10-11。使用隔离 MySQL 8.0 Testcontainers、JDK17；微信离线协议与构建验证。未接真实微信资金、身份或设备。

## 规则与真实数据库证据

- CommissionRulesTest：2项，上海时区自然月末日截断、3% HALF_UP 分币舍入。
- JdbcCommissionLedgerTest：16项，实际核销事务唯一应计、幂等与并发、下单冻结后政策/门店费率变更不改金额、自然月边界、未知政策/旧单/券单金额保持 null、跨店/店员/失效会话隔离、V026可信批准来源回填与重复执行。
- 同类验证台账写失败时核销与归档整体回滚；实际 R2b2 退款通知台账写失败时退款终态和通知事件整体回滚，重放一次成功；非全额/错币种拒绝。
- 原应计负数冲销用受控数据库夹具验证，不代表开放已完成订单退款。R2b2只支持完成前取消；该真实路径记 REFUND_NO_CHARGE，不虚构已收佣金或资金结算。
- JdbcReservationsTest：13项，包括新增下单唯一快照、快照写失败时订单/名额一起回滚。
- MerchantOnboardingMySqlTest 新增1项：批准来源/同一时点/自然月/政策幂等，政策写失败时商家、员工账号及申请批准整体回滚后可同键重试。
- CommissionHttpTest：4项，真实 Spring 路由和安全链、仅店长、参数重复/未知/边界、no-store、无写接口和安全503；业务服务是 mock，不计穿透真实库的 HTTP 端到端。
- PaymentNoDatabaseTest：3项，其中新增佣金数据库未配置503。

最新本地定向组合：39项（2+16+13+4+3+1），失败/错误/跳过均为0。前次59项为早期版本的佣金与原核销16/退款20/入驻8回归，其中用例有重叠，不相加。收口发现新增入驻回滚断言误写 PENDING，已修正为实际 PENDING_REVIEW 并独占重编译重跑；CI以最新提交为准。
