## 真实操作与辅助界限

核销码从车主实际原生详情读取；商家填表、车主评分/文字、来源订单导航通过官方原生元素事件。相册 API 只辅助返回本阶段实际微信文件系统 PNG 路径；确认/取消只辅助系统回调。没有 mock 上传、扫描、业务请求/响应、页面业务数据或后台归档任务。

`nativePickerClickAccepted=false`、`nativeModalClickAccepted=false`。未宣称真实相机、实际系统弹窗/选择器点击、手机真机、人工签名或正式扣款通过。`/access` 成功仅表示私有授权，不表示图片实际渲染或证书下预览通过。

消费者 `SERVICE_ARCHIVE_ENABLED=true` 在隔离本机原已启用，间隔 1000ms；脚本先核验，拒绝未启用环境，未修改正式配置。每次新建独立订单，既有评价/任务/审计不重置；签字证据不纳入施工档案照片。另一车主 ID 先校验归属/活跃状态，再生成短会话，不覆盖外部身份。
