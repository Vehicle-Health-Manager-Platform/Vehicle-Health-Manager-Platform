## 真实 HTTP 29/29

命令：`node scripts/local_service_archives_e2e.cjs --allow-local-test-writes`。脚本验证固定隔离镜像、表数、JAR、合成身份及此前真实 HTTP 核销订单，再运行；拒绝不匹配环境。没有凭 COMPLETED 伪造核销记录，也没有 mock 业务成功响应。

## gstack H5 实际交互

使用用户指定 `/browse`。仅登录用短时合成身份桥接，JSON、任务、档案和图片授权均接真实后端。档案页实际展示“施工自动归档”、真实30分钟、本次无配件、报工/签字/核销时间与测试提示；点击来源订单进入本人已核销订单；离开/重入可重新查询；首页最近档案显示测试标注。

施工图片按钮确实发起授权并打开预览容器，但浏览器图片 naturalWidth=0：已有本机自签证书直连预览仍未验收通过，不能将预览容器打开计作图片加载成功。Node可信公钥证书下载通过不替代H5/微信直连图片验收。

本机开发监听需与gstack处于相同授权主机网络，沙箱监听会连接超时；Windows浏览器会话需在同一命令期间完成交互。截图在 `.cache/a7-archive-page.png`、`.cache/a7-archive-home.png`，不进入仓库。
