## 本机隔离与合成边界

仅vehicle-auth-local命名Docker项目、固定回环127.0.0.1:18080、独立网络、精确镜像vehicle-auth/backend:a7-experience-publication及V019/61表。写入前核对运行JAR与当前构建SHA256一致；迁移前备份，V019重复执行两次。发布开关只在此隔离栈开启，默认配置仍false。

独立合成订单9207641、合成车主/车辆9207590与同款读者9207591。原LOCAL_TEST订单9206401及其核销test_mode=1保持原样。新订单的WECHAT通道、支付事件、核销及复制的文件元数据均为直接数据库合成夹具：**没有真实微信支付、回调、扣款、质检签字或图片上传**；不将这些数据作为正式施工凭证。公共接口不返回图片，复制元数据的对象不用于私有图片预览验收。

运营账号由现有后端JAR的无HTTP operator-admin CLI创建，随机密码、OTP和JWT不输出。合成OTP仅由独立测试脚本写bcrypt哈希，不增加生产绕过接口；未配置OperatorSmsSender的真实发码接口503已验证。车主会话使用已有本机合成JWT桥，不代表wx.login。CLI必须保留本机local-payment-test profile；首次脚本覆盖profile导致拒绝启动，已修正，不改变生产规则。

## 复核命令与清理

先在受控隔离栈备份并应用V019、安装当前JAR、显式开启消费者/卡片/发布。准备合成bcrypt工具：

```powershell
python scripts/local_publication_crypto.py
node scripts/local_experience_publication_e2e.cjs --allow-local-test-writes
```

该脚本严格检查命名栈、当前JAR、来源合成标记与ID碰撞；只重置已验证合成订单的衍生评价/归档/卡片，不修改原测试来源。正常运行会撤销生成会话并禁用合成运营账号；--keep-ui仅供短时本机辅助验证，完成后必须退出并撤销所有保留会话、禁用账号及删除忽略目录中的会话文件。临时H5/回环转发停止，凭据/私有备份均不上传。
