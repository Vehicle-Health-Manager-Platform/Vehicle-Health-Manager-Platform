# R9-A2a 本机录音与辅助材料验收

日期：2026-10-18。前序为[PR156](https://github.com/Vehicle-Health-Manager-Platform/Vehicle-Health-Manager-Platform/pull/156)本地预览；本阶段落实A1详细设计和A2a本机采集，不宣称整个A2或语音识别已经完成。

## 本次实现

- 原生运行时透传录音管理器、音频上下文、PDF选择器；共享材料组件接入实际AI与新增档案页。
- 1–60秒MP3录音、3MiB限制、试听/停止/取消/移除；图片/PDF每份10MiB，总数3份。本机路径白名单，拒绝远程URL/UNC及非法文件名。
- 单例录音租约保留到最终事件，重复终止事件去重；隐藏、卸载、切号、换范围及晚到回调不恢复旧材料。
- 系统选择器返回时同账号/范围的候选可恢复，辅助选择器暂时隐藏不清空本人档案手填内容。
- 材料只保存在内存，不进入文本AI正文或档案file_ids；AI有材料时提示仅发送文字。预览构建仅允许本机图片预览，仍阻止远程文件和真实写入。

## 实际验证

- 完整小程序测试 **891/890** 通过，0失败/跳过；比前序874新增17项（16项采集状态/边界测试及1项实际运行时装配测试）。
- 普通微信构建、原生公共样式与无测试身份桥检查通过；H5构建通过；独立演示构建通过。
- 检查普通构建全部JS：没有演示身份、诊断钩子或演示地址。
- 开发者工具已加载实际AI和档案录入页，截图并检查本机材料组件、录音/图片/PDF按钮和限制提示；截图位于忽略目录 `test-results/a2a`。仅页面装配与合成身份，不声称模拟器完成物理录音或真实文件选择。
- 无后端/SQL变更，OpenAPI仍350操作，数据库基线130表；本次未重跑后端全量或真实数据库，由阶段PR原CI门禁提供最终回归。

## 保留边界

没有接ASR/OCR、多模态模型或音频/PDF后端上传，现有图片白名单保持。真实麦克风、试听、系统选择器和权限在iOS/Android真机另验。移除只清内存引用，不宣称删除微信临时文件或用户原件。

下一A2b先明确受控媒体上传的独立格式、扫描、用途授权、幂等与访问契约，再实施后端和上传界面；之后A3识别候选确认。正式外部接口仍在B段。
