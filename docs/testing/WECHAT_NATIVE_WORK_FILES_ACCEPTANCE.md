## 自动化辅助的明确范围

- `chooseMedia`/`chooseImage` 仅返回真实微信文件系统的合成图片路径；实际选择器点击、相机与真人图片未验收，`nativePickerClickAccepted=false`。
- `showModal` 仅辅助确认/取消回调，真实系统弹窗点击未通过，`nativeModalClickAccepted=false`。取消后检查对应数据库无写入。
- 官方元素 change/input 事件填表；canvas 使用实际 touchstart/move/end，实际 `canvasToTempFilePath` 导出及真实上传，未 mock 画布、文件导出、上传、扫描、业务请求或页面业务数据。
- 本阶段不导出身份令牌、私有 URL 或真实用户图片。合成笔迹不作为真实人员签名凭据，测试支付不代表真实扣款。

## 诊断与清理

首次读取文件大小误将 `statSync` 的直接 Stats 当作 `.stats`，已修正；诊断源文件按名称与完整内容校验后删除。另发现恢复未安装 mock 的 API 会破坏开发者工具 API，已用安装追踪及回归测试修复，并只重开隔离项目恢复原 API。

正式构建曾误报 `terser not found`；锁定依赖恢复后仍失败，进一步定位为沙箱拒绝依赖包 `realpath`（EPERM）。恢复临时诊断改动并在允许环境构建通过，未修改依赖清单或构建逻辑。

最终撤销五个合成短会话、清空身份桥、恢复本次实际安装的 mock、删除本阶段源 PNG。后续文件列表为空且两个选择 API 仍为函数。画布运行时临时文件不宣称已逐个删除；服务器合成订单/扫描证据/审计保留于隔离环境。
