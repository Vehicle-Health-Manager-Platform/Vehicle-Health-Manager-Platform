## gstack H5 实际操作

390×844视口，真实H5页面经仅回环CORS传输桥发送所有业务请求到真实后端。

1. 无评分/说明时提交控件 `disabled=true`；选5分、填写文字才允许提交。
2. 实际二次确认说明不可修改/仅本人可见；取消后数据库评价数为0。
3. 离页再入，文字为空、评分未选、草稿图片清空；账号/弹窗/请求竞态另有状态流测试。
4. 图片经页面真实文件输入→本人私有上传→真实扫描，显示“上传完成”。无头Chromium原生选择器会自动cancel，验收只在浏览器捕获并抑制该cancel后用gstack `upload` 放入真实PNG；不改产品、不模拟上传或评价响应，因此仍不代表真实手机选择器或拍摄验收。
5. 带1张真实图片、评分和文字确认提交；出现本人只读评价/时间/测试来源，编辑控件消失；数据库评价/图片关系/创建审计各1。
6. 实际返回再进入，成功状态从服务端读取，仍为同一本人记录。截图已检查，保存在忽略目录 `.cache/a7-owner-review-reloaded.png`。
