# 本机商家报价验收

2026-10-06。隔离 Docker 项目 `vehicle-auth-local`，后端 `127.0.0.1:18080`，H5 验收服务 `127.0.0.1:4317`。只写合成项目与商家，不连接生产库。

## 前置与复现

1. 编译后端与小程序/H5，按 V001–V006 迁移隔离测试数据库；后端使用本机私有配置，勿输出或提交配置值。
2. 在开发者工具打开本工作树小程序产物并启动自动化端口 9420；车主验收通过真实 `wx.login` 换码。
3. 运行 `node scripts/prepare_local_service_catalog.cjs --allow-local-test-writes`。脚本固定 Docker 项目、合成 ID 和字段，遇到冲突拒绝覆盖。
4. 运行 `node scripts/local_business_harness.cjs --allow-local-test-writes`。商家助手只在此显式启用、回环且同源的测试服务内生成 10 分钟签名会话，并写入真实会话表；不增加生产接口或修改短信适配器。
5. 用 gstack `/browse` 打开 `http://127.0.0.1:4317/?quotes=unique#/pages/merchant/index`，执行 `eval apps/miniapp/test/local-merchant-quotes-browser-flow.js`。
6. 结束后停止验收服务。脚本 finally 和服务关闭时撤销本轮商家会话，车主也执行真实退出。异常终止遗留会话最迟 10 分钟过期。

商家登录响应使用明确的合成桥接，未发送或验证真实短信。报价读写、价格排序、权限、版本、幂等和审计均调用真实后端与 MySQL。浏览器不输出账号凭据、JWT、微信 code 或完整签名地址。
