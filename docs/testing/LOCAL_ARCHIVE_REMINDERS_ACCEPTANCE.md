## 行为口径

- 日期按 Asia/Shanghai，当天即到；保养日期与里程任一到即 DUE。不自动完成、延期或推断保养周期。
- 里程目标存在、登记里程未知且没有已到日期目标，状态 UNKNOWN；无配置为 NOT_SET，均不能当作正常健康。
- 来源限定手动/附图的本人保养、保险、年检；源无效则 UNAVAILABLE，隐藏旧 ID 和目标，停止触发。
- 替换来源需要版本和明确确认；停用保留配置；写入/审计/回执原子，回执重放仍检查现时授权。
- 这是个人填写目标，不是证件合法性、官方到期信息、健康诊断或六指标评分；不扩大门店/技师或分享接收者权限。
