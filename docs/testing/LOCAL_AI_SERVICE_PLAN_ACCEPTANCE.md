# R4c1 本地验收

1. 有效车主读取限定目录，停用/删除项目不在候选；超过40条明确计数、可手动转全部服务。
2. 填写问题、指定最多3项，取消第三方用途确认不生成；规范问题不传身份/车辆档案或价格，模型只见规范问题/公开目录/标准项目号。
3. 模型替身选择有效推荐/可选，服务器补当前项目名称/分类，保留完整规范问题证据；指定项目先列出，不能伪造必做、商家或价格。
4. 模型未知ID/重复/指定重选/证据改写/额外JSON等明确MANUAL，仅保留指定；关闭或未配置同样降级。指定项目在前40之外仍被有效纳入；停用404。
5. 生成中目录变更/失权重新核对，SOURCE_CHANGED空方案或401/404，无外部IO事务；没有持久化问题/方案或业务审计。
6. 推荐条目只带标准项目号进入既有服务详情，当前报价/预约页仍重新读最新版本、可用时段与下单资格；没有报价/时段时手动选其他项目。
7. 编辑问题或选项清旧结果，离开/换账号清草稿、目录与方案；迟到回调无效，未确认或旧结果不能生成报价跳转，URL无问题/证据。
