## 可复现真实 HTTP

```powershell
node scripts/local_order_redemption_e2e.cjs --allow-local-test-writes
```

脚本仅支持固定隔离测试项目、镜像、网络、端口和表数；验证合成 ID 冲突后仅清理约定测试订单的关联记录。需要本机测试支付原有 profile、开关与密钥，以及已运行的私有上传/扫描基础设施。登录会话为合成测试桥接，密钥不打印；结束撤销会话。报告 `test-results/local-redemption-e2e.json` 忽略 Git。

结果 **50/50**：真实测试支付创建与 HMAC 回调→PAID 事件→七张实际私有上传/扫描→接车→车主确认→派工→本人接单→防护→完整报工→PNG 质检→核销完成。对付款金额、付款事件、签名、确认的临时失效检查，以及无权限/外店/非待核销/通用动作绕过/无键/未知字段的拒绝均成立。五次错误持久记录，第六次包含正确码被 429+Retry-After 阻断。合成窗口调整仅用于验证下个窗口恢复；生产不提供解除限额接口。

原键响应一致，新键 changed=false；订单唯一核销、ORDER_COMPLETE 迁移与 audit_log 各一条；车主完成后不再展示码、本人可读结果、他店不可读、撤销会话不能重放。核销幂等缓存不含码或内部身份/付款凭据。

首轮夹具缺少 appointment_at，支付创建被拒绝；已补齐合成预约时间。第二轮脚本变量 process 遮蔽 Node process、默认错误码断言有误；修复后第三轮全部通过。未修改支付服务或放宽业务门禁。

## gstack 实际页面操作

使用 `/browse`、390×844 H5。只将登录替换为合成会话；回环 CORS 测试桥转发全部真实 HTTP 业务响应。未使用业务假响应。

- 待核销页显示订单、金额与“测试核销，未真实扣款，不可作为收款凭据”。五位码不能提交；六位码打开二次确认，可取消。
- 车主待核销页展示原六码；离开商家页面后返回，输入已清理。
- 实际输入、确认核销，商家显示完成时间、测试标识，输入与提交入口消失；车主显示已完成与核销时间，码不再出现。
- 移动尺寸核销结果已截图检查，调整嵌套结果为逐行展示。

H5 预置命令：追加 `--prepare-ui` 可保留待核销合成会话于 `.cache/a7-ui-sessions.json`；完成验证必须撤销并删除此文件。临时 H5/桥服务只绑定回环，并在联调结束关闭。
