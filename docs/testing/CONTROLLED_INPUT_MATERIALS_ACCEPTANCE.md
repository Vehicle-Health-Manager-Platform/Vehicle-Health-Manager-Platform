## 验收步骤

1. 服务关闭/未配置时正式车主上传应失败503；小程序缺少直达地址应本机提示；演示不成功写入。
2. 启用本地测试环境上传本人车辆MP3/PDF，得到材料ID与CLEAN；响应不含文件名、路径、file_id或对象键。
3. 原key同材料返回同收据，同key改内容409；不同用途/车辆独立隔离。跨车主、商家/技师、已转移车辆、撤销会话拒绝。
4. 空文件、超限、伪造/截断/越界MP3、加密或活动PDF、病毒、扫描不可用均失败；失败不得产生成功材料。
5. 对象写完转移车辆或审计失败，应无材料记录并清理对象；补偿失败可恢复，已成功对象不被误删。
6. 本人原用途签发60秒附件访问；错误用途/车辆、软删除、签发期间转移车辆拒绝。原图片入口继续不接受音频/PDF。
7. 页面显式上传，失败可原key重试；切号/换车/隐藏/移除不接收晚到收据；文本提问与档案保存payload仍不包含材料。
