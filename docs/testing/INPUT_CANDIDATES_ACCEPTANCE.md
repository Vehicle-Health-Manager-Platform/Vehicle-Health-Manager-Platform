## 人工复验步骤

1. 正式车主新车登记先选择车型；候选填车牌/VIN/里程，检查前原表单不变。检查并勾选后带入，再点原保存才入库，不解码车型。
2. 本人车辆新增档案，候选填标题、日期/里程/备注，空项保留原值；带入不发送保存请求。原保存沿用当前manual/photo规则；失败可原key重试。
3. 行驶证结构化页带入候选后owner_confirmed仍false；按原表单完成来源核对再保存，revision冲突不能覆盖。
4. AI语音人工整理只带入文字草稿，用户点击发送才调用文本API；切换车辆清空旧草稿。
5. 修改候选取消核对；整理期间修改原字段、保存中、切号/换车/档案版本变化或离页时不得应用旧候选。格式错误不能部分带入。
