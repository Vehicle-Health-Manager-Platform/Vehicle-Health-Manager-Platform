- 同类覆盖退款通知重复/乱序、变更哈希/供应商流水冲突、提前通知/错金额、提交响应丢失后新worker先查不再提交、FAILED只查、失联租约与旧worker围栏；actualSignedSupplierHttpCommitsOriginalRefundInMysql用实际HttpServer签名回执写入真实MySQL，并保持原支付成功/订单关闭。
- LocalRefundChannelTest：7项。HMAC/规范化哈希、重复/未知/尾随字段、零金额/币种/时间窗/原文大小、生产/外部源禁用、404未知与202已知处理中、提交原支付与固定幂等号、签名回执原退款绑定、重定向/503/超大/慢body拒绝。不会将测试协议当作微信协议。
- RefundHttpTest：6项。Spring MockMvc真实路由/安全链、伪造/非测试回调、角色拒绝、严格请求、no-store、通知ack与数据库失败503；OrderRefunds/RefundRecovery是mock，不宣称该套业务HTTP穿透真实库。
- PaymentNoDatabaseTest：2项（其中新增1项退款门槛）。数据库未配置503；测试渠道关闭回调404。
- 微信离线294项：新增8项退款严格字段/双同意、仅理由或版本写入、必需幂等键、拒绝理由、核对空体/无键、响应订单绑定、私密错误过滤、未知结果原键重试、身份与隐藏丢弃旧结果。
- 微信构建和原生公共样式/正式包无测试身份桥检查、兼容H5构建通过。构建不等于微信开发者工具实际操作。
