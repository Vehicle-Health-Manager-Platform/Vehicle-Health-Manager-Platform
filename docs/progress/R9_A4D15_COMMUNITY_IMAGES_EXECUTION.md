# A4d15 社区图片真实存储与授权发布验收

2026-10-22，基于 PR205（分支 `codex/r9-a4d14-invitation-rewards`），实施分支 `codex/r9-a4d15-community-images`。核对时 PR205 八项远程 CI 全部成功。

## 完成内容

补齐已实现社区图片11接口的所选历史执行证据：来源、预览、本人列表/提交/撤回/历史预览、运营列表/审核预览/审核、公开列表/PNG读取。没有增加生产业务接口，也没有修改生产发布开关或 schema。

- 原图和独立副本通过真实HTTP上传，实际存入私有MinIO并经ClamAV引擎扫描。
- 副本带合成私密PNG文本元数据。生产渲染器去除元数据并保留所提交像素；预览、本人/运营预览、公开PNG及数据库保存字节一致。
- 父经验同意/审核、人工档案关联、图片预览哈希、同意版本及独立副本约束使用真实生产HTTP实现。
- 注入仅针对图片审核的审计失败触发器，确认事务回滚，再以原幂等键成功重试。
- 三份申请分别经历批准→撤回、拒绝→撤回、批准→父经验撤回→图片撤回；最终三份均WITHDRAWN/revision3，九事件、九审计。
- 撤回后旧公开ID持续404；重复旧同意只返回原回执、旧审核请求冲突；新申请生成新UUID且不会恢复旧地址。本人仍可查看可信历史副本。
- 校验跨车主、车型不匹配、车辆归属、角色和运营审核权限；公开列表仅含public_id/width/height/published_at，原图不签名访问403。
