# A4d37 微信档案里程识别入口

2026-10-24，承接 PR227 / A4d36，仅微信小程序与现有只读网关协议。

## 已实施

档案新增页通过已有“材料内容核对”组件选择一张已上传图片，并显式同意本次用途；无选图或同意不发请求。请求仅携带当前车主 JWT、车辆/图片标识、同意版本，复用直连/云托管 JSON 传输，不向客户端提供 OCR 服务密钥。

客户端严格核对响应车辆、图片、确认要求、字段集合、整数里程范围和状态/可信度一致性。CANDIDATE 和 LOW_CONFIDENCE 都进入原人工检查、勾选确认、确认带入流程；AMBIGUOUS/NO_CANDIDATE 不挑选里程，失败保留手动整理。无自动保存或更新车辆登记里程。

切换选择、撤回同意、身份/车辆/档案类型/图片集合变化、隐藏/卸载或取消会废弃候选；底层无 abort 能力时仍能结算取消并丢弃晚到回调。识别期间禁用原表单、上传和保存，保留取消。原表单变化时沿用候选快照保护。
