沿用积分正文审计并允许调用者明确本域17接口覆盖数，仍逐条核对实际JWT、方法/路径/query、正文源版本与Idempotency-Key；不允许缺少/重复/失败/跳过断言。后台与MySQL、网络按本次归属清理，原始日志和环境不提交，仅提交脱敏摘要。
