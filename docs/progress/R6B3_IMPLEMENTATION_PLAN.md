## 解锁设计

采用即时资格计算，避免把资格缓存为永久权利。阈值为1–1000000整数，政策窗口UTC，月份以Asia/Shanghai确定；只计算当前账号来源为user的VERIFIED_WECHAT、QUALIFIED有效新客，且新客账号当前有效。资格范围仅非实时诊断，不代表人工在线、即时接单或资金权益。

无政策UNKNOWN、未来NOT_STARTED、到期EXPIRED、未达人数LOCKED、达到ELIGIBLE。资格返回政策版本、来源说明、阈值、本月有效人数、可用截止时间（政策截止和下月起点取较早者）；停用后无有效政策立即UNKNOWN。R7在真正提交留言的事务重新校验，不接受客户端eligible标记。

政策停止不重开，变更创建新政策；原始归因/月度历史统计不改，当前资格单独复核新客账号状态。发布不发券、不占库存、不开放实际留言API。
