## 范围与设计

14接口、131请求/448断言：本人经验卡列表、授权、撤回；独立审核待审队列、批准/驳回；同款公开列表与UUID详情；独立精选来源列表、草稿创建/列表/详情/修订/发布/停止；车主运营精选入口。每接口具备正常、边界、错误、未授权证据。

覆盖固定公开字段白名单、不泄露施工/评价原文、跨车主/角色权限、来源哈希确认与CAS、未来窗口前隐藏/生效后展示、发布冻结/停止不重开、撤回清除授权与公开/精选同步隐藏、旧键拒绝、永久创建回执恢复、再次授权审核产生新UUID、旧UUID不复活且旧精选不自动改绑。拒绝后仍可撤回；LOCAL_TEST卡始终不能授权。

独立运行入口 --experience-cases 与其他套件互斥。新增准备钩子等待真实归档消费者完成两条任务后再记录131表基线；避免把异步夹具初始化混入匿名“不写表”检查。等待有30秒截止，不能只生成一张卡即放行。公开UUID取自实际列表响应，审计绑定全部后续详情路径、实际身份令牌与全部断言。

精选时间窗在首次创建前按当前UTC整秒设置未来60秒；真实请求等待窗口生效再核对展示，不回拨系统时间、不修改已发布行/审计。

## 夹具与交付边界

两份已完成订单/支付事件/核销/施工/评价/待归档任务为SQL合成夹具。其中一份channel=WECHAT、test_mode=0用于来源协议，另一份LOCAL_TEST/test_mode=1用于永久排除。合成支付号/事件hash不是供应商凭据，不代表真实付款、回调验签、身份核验或正式内容合法性通过。每份施工使用独立的合成安全文件；无真实用户或既有数据库。

档案、来源快照与卡片由服务真实消费者生成，授权、审核、精选配置全部经HTTP产生。仅隔离进程开启归档、卡片及经验展示开关；正式默认配置不变，不调用外部AI。原始JWT、私有环境、Newman正文响应仅留忽略目录.cache；提交脱敏数量、哈希与不变量报告。
