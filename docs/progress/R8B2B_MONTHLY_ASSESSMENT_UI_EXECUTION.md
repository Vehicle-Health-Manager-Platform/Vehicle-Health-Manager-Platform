# R8b2b 月结查看、确认和恢复执行

2026-10-16，本地完成。按[设计](R8B2B_MONTHLY_ASSESSMENT_UI_DESIGN.md)接通R8b2a，无新增结算业务规则或迁移；整R8完成前不上传。

## 实现

- 七个严格只读接口：服务器门店/月当前版本及筛选历史；店长本店上下文/历史/详情/事实；员工本人冻结归因计数。独立运营权限/当前门店与角色实时核验，跨店或普通员工全店读取拒绝，员工不能选择同事。
- 月份头与最新冻结记录同一事务核对，不从一页历史推测版本；整月政策预览使用无FOR UPDATE只读查询，未结算不会生成记录。R8b1scoring_available=true仅表示读取能力接通，不保证已出分。
- 运营实际页从有效门店选择、明确读取月/服务器修订、政策目标/证据/等级/来源预览，再冻结确认原正文。历史/依据分页与最新结果展示；共享组件区分未知、真实0与候选统计，保留修订/采集时间。
- 本店页先服务器确认角色，店长读全店、普通员工只读本人计数，无新客身份或其他员工明细；不同请求中若版本变化则重读，避免混合新旧。切号/隐藏清空、迟到响应无效。
- 月结独立账号存储与政策互不覆盖；永久原键恢复、存储失败阻写/清理失败保留、401及CAS、跨页比较。原门店失效后仍能独立验证运营权限、读历史并恢复成功原回执；无法新结算失效门店。
- 两个新静态路由及登录回跳拒绝额外查询，运营工作区/政策页及门店入口已连接；页面有加载、错误、空数据、权限和禁用状态。没有新增正式渠道或默认授权。
