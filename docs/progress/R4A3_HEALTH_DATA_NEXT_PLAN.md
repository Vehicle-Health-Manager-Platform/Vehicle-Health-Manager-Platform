# R4a3 健康数据来源与指标口径下一步

日期：2026-10-12。R4a1到达提醒、R4a2本人三类资料已编码上传；可信健康测量与评分仍欠。

## 分段规划

1. **盘点**：按交付首页/车辆页六指标逐项列出名称、适用车型、已有施工证据、数据源、时间及单位。区分动力电池与低压电瓶；区分本人填写、门店工单测量和供应商来源，不把照片/项目名称当测量。
2. **冻结数据规格**：选择可独立采集的指标及来源确认流程，定义可缺失字段、测量时间/方法、单位、关联档案/工单和来源失效规则。没有数据为“未知”，不默认健康100%。不自行发明安全阈值、权重或数据有效期。
3. **后端**：指标快照和最小本人读写、来源授权/版本/幂等/审计，旧资料兼容；不开放门店/技师读全档案，工单来源权限在其独立规则内完成。
4. **微信**：来源与测量值查看、录入/确认/修正、缺失或过期资料提示及个人车辆切换。先完成可追溯数据，不显示未经批准算法的百分比分数。
5. **验证和上传**：真实数据库/HTTP边界、单位/类型/时间、跨车/跨店及重复提交、生命周期和原生产物；中文文档与独立PR，设备/真实供应商待验项单列。
6. **评分另行冻结**：阈值、权重、未知项处理、车型适用、版本及可复算输入须有明确依据；提供具体方案让用户复核业务判断后再编码评分。数据来源不足时推进R4b可独立业务，保留R4a缺项。

## 保留欠项

驾驶证/违章完整结构化信息及官方来源、首页五类提醒、提前提醒、订阅发送；R3a2/R3b供应商识别与R9正式微信/SMS/资金/真机不因本阶段字段补齐而销项。后续R4b→R4c→R5→R6→R7→R8→R9；无PC。
