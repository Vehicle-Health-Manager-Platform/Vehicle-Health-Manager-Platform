## 第一单元范围

1. 核对已有标准项目/车主报价/预约、门店资料与region_code；冻结向有效车主公开的门店最小字段（名称、已批准区域、服务地址、营业说明与在售标准报价等，逐项审查）。申请资质、联系人私有手机号、员工/客户信息不得因详情接口公开。
2. 有效门店详情与区域筛选/选择：启用、未删除、审核通过的真实门店与有效目录项目；手选来源于已有批准区域，不虚构覆盖范围。用户没有选择区域时明确显示范围，列表/报价分页、失效与空态完整。
3. 微信服务列表进入详情，复用有效报价与时段选择到预约；报价/上下架/容量变化服务端重新校验，不能用详情缓存价下单；区域和车辆/账号切换清理旧请求。
4. 后端权限/最小投影/停用和报价失效/分页测试；微信区域选择、详情、预约回跳、弱网/生命周期及原生构建；中文文档、分阶段PR、最终六项CI与待真机项目。
