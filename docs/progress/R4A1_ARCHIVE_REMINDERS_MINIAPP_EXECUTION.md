# R4a1 微信目标与提醒执行

日期：2026-10-12。依赖 R4a1 后端。

## 交付

- 本人档案页增加车辆提醒列表入口；本人手动/附图保养、保险、年检记录增加来源设置入口。
- 来源设置显示记录类别/日期及当前配置；本人填写日期/保养里程，不预填周期。更换来源显示原目标并确认；停用另行确认。
- 首页当前车辆三类摘要与单独提醒页，显示服务器核对日期、登记里程和触发原因。未设置、停用、来源失效、未知里程、未到目标和目标到达分别呈现。
- 严格检查响应字段、车辆/来源匹配、状态与目标一致性。失败可重试，同载荷复用内存 UUID；改载荷换键；冲突必须刷新后复核。
- 登录可返回目标/提醒页。隐藏、退出及切换账号/车辆立即清理私有内容，迟到响应不恢复旧内容。HTTPS/云托管复用已有传输层，无私有目标本地缓存。

## 验证

微信离线测试 **351/351**（新增服务协议 5 项、状态流 5 项），覆盖日期/里程输入、未知状态、严格投影、受控错误、来源/车辆不匹配、重复点击、确认取消、停用、冲突、幂等重试和生命周期。

微信 mp-weixin 与兼容 H5 构建通过；普通微信产物无测试身份桥，共享样式检查通过。新增 `pages/archive/reminder`、`pages/archive/reminders` 注册在 app.json 且各有 WXML。

构建和离线测试不代表开发者工具完整页面操作、日期选择器/系统确认实点或 iOS/Android 真机验收；这些仍需独立记录。没有订阅消息发送、提前提醒或证件合法性判断。完整 R4a 的其他结构化字段及评分尚未完成。
