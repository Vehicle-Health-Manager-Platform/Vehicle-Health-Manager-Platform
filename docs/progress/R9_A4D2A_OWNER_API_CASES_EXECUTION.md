# R9 A4d-2a 车主车辆与档案 API 业务验收

## 计划与实施

2026-10-19：先完成不依赖外部服务的车辆与档案验收，再开展预约履约、券与本地资金协议，之后补商家/运营领域及剩余车主接口。正式微信、支付、识别接入继续后置。

本阶段新增默认关闭的 Postman 集合、案例清单、隔离身份/数据夹具与严格证据校验：8 个接口、61 个请求、204 条断言。每个接口均覆盖正常、边界、错误、未授权；同时检查跨角色、跨用户、幂等重放、请求编号换内容、车牌/VIN 脱敏及外部用户数据未改变。保留已有 338 项匿名门禁及默认业务模板禁发检查。

测试身份仅在全新隔离库创建会话并签发短期 JWT，调用真实 Spring HTTP 和 MySQL。私有环境及 Newman 原始日志仅留在被忽略的 .cache，CI 仅上传脱敏汇总。

## 当前验证

2026-10-19：A4d-2a 本地 PASS（172.671 秒）：8 接口的正常/边界/错误/未授权案例共 61 请求/204 断言全部通过；338 匿名请求/1014 断言通过，默认模板实际 0 请求。131 表匿名前后行数一致，业务结束车辆/档案各 2 条（其中本用户各 1 条）、幂等/审计各 2 条，跨用户数据不变，源码哈希一致，后端/MySQL/网络清理成功。7 项新增、9 项既有脚本测试及编译/diff通过。下一 A4d-2b 预约履约/券/本地资金→其他域→A5→B 外部接入→C 真机；全部 API 业务验收仍未完成，性能延迟未达标保留。
