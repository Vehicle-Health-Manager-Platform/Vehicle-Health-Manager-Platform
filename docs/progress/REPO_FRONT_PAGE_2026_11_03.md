### 为什么 `<img>` 引用的 SVG 能播

GitHub 渲染 README 里的 `<img src="....svg">` 时，浏览器把该 SVG 当作**独立的 image document** 加载：
脚本被禁用，但**动画照常执行**（SVG 的 secure animated mode）。本图的动画全部写在 SVG 自身的 `<style>` 与 SMIL 里，
不依赖页面脚本，因此不受 GitHub 过滤 README 内联 `<script>` 的影响——这正是它能在这里播、而 JS 方案不能的原因。

两条独立技术路径同时使用，任一被支持即可见效果：CSS `@keyframes`（虚线流动、节点光晕、深浅色变量）与
SMIL `animateMotion`（六段链路上的数据包位移）。

**唯一不播的场景**：操作系统或浏览器开启"减少动态效果"（`prefers-reduced-motion: reduce`）时，
按无障碍规范停止动画，此时呈现的是一张完整可读的静态流程图——这是刻意行为，不是故障。
