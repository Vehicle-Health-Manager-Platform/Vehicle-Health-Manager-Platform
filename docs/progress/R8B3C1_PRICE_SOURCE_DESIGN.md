# R8b3c1 价格监控来源配置设计

2026-10-16，用户确认按具体门店报价版本配置、运营确认内容/单位/车型适用性、来源/有效期及含边界价格区间；改版或来源变化未知，偏离仅需核对。整个R8完成前不上传。

## 分步方案

先做c1独立权限与可核验来源配置，再做c2只读比较。跨店统一比较还需报价模型中明确单位与车型适用字段；首版选报价版本绑定，能直接复用当前数据并明确限制，避免把不同服务混比。标准项目参考价未经本步来源确认不作为阈值。

独立can_price_monitor默认0，离线显式授予/撤销与审计、会话撤销同事务。V056仅新增权限及一张price_monitor_policy表，仍保留旧数据，无种子/历史回填；116表。登录增第十一布尔权限位，精确13字段，兼容已知旧响应。

## 来源与字段

只从服务器当前有效门店、有效标准项目及上架报价取候选，分页20。原最新报价版本必须与当前价格/上架一致，有原员工及匹配保存审计；标准项目须有来源说明。遗留迁移初始版本或破损来源标UNKNOWN，不能创建已确认依据。服务器将门店/地区、标准项目当前内容/质量/来源/修订、报价版本与价格及原来源证明规范化哈希，返回最小来源快照。客户端仅提交quote_id/source_hash，不能自报快照或有效版本。

运营填写两位正数下限/上限（0.01–99999999.99，下限≤上限）、price_unit、applicability_note、source_note、未来生效与截止时间，明确scope_confirmed=true。服务器复核同一来源哈希，冻结快照，不宣称运营文字已经成为结构化车辆适配规则。

## 状态与恢复

草稿CAS修订；发布前再次核验当前来源和未来窗口，发布后冻结，只能停止，不重新开启。同一报价最多一条PUBLISHED（到期后仍须显式停止再替换）；新版本确认创建新依据。停止不依赖原门店/项目仍有效，保证失效来源可停用。

沿既有WriteIntegrityService统一幂等与成功审计，创建另保存永久主体/键/规范化请求哈希及原结果；通用回执过期、来源失效或政策停止后，同主体同键同正文返回原创建结果，先检查当前独立权限。键改正文拒绝。审计失败原子回滚，发布唯一约束并发不产生双生效。

运营实际配置页展示服务器来源、明确确认、政策状态与持久原请求恢复，切号/失权/隐藏丢弃迟到响应；未知结果仅原键正文重试，不新建重复依据。独立账号存储、跨页比较清理与原有政策存储隔离。
