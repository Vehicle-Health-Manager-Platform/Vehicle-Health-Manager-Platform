申请即车主同意，等待店长期间保留原履约流程。接受必须申请前状态仍一致且可信原支付全额一致；双方同意与订单关闭/容量释放在同一审计事务。资金按供应商单独核对，不因订单关闭标记成功；失败不恢复订单，成功不可反转。

退款供应商使用独立LOCAL_TEST协议且仅本机HTTP源，总响应3秒/16KiB；先查询、同退款号提交、持久租约恢复。默认REFUND_RECOVERY_ENABLED=false，正式WECHAT退款尚503。原支付保持成功，历史退款不补造同意；旧/软删除退款阻断重复退。

详见[中文契约](../api/ORDER_REFUNDS.md)、[验收](../testing/LOCAL_ORDER_REFUNDS_ACCEPTANCE.md)。本地最新定向35项、微信294项及微信/H5构建，最终六项CI以#102检查和摘要为准。MockMvc角色/请求测试与独立HTTP供应商+真实MySQL落库分开记录；真实身份、原生页面和资金不在此证据内。
