# A4d18 认证会话轮换与退出验收

2026-10-22，基于PR208，分支 `codex/r9-a4d18-auth-sessions`。开始时前置PR已完成检查成功，后端及性能仍运行，未声明全绿。

## 完成范围

补齐3个已有接口的所选历史四类证据：`POST /api/auth/refresh`、`POST /api/auth/logout`、`POST /api/auth/operator/logout`。`GET /api/vehicle/list`为会话存活支撑，旅程共4接口，不重复计算已有覆盖。生产Java、schema及生产开关未改。

注入明确的合成已登录身份和12份会话，原始刷新值仅以SHA256存入数据库。车主、商家、技师通过实际HTTP刷新，取得新访问/刷新凭证；900秒JWT的HS256签名、subject/role/app/jti/门店/绑定及用户投影与原会话一致。旧refresh被拒；旧access在刷新后仍有效，直到同会话退出。不能把刷新入口无Authorization当作未授权，它以refresh本身授权。

未知、短/超长、缺失或格式错误凭证被拒；已撤销/过期、错应用、停用车主、停用员工、运营会话均不能通过普通刷新。错应用及身份停用导致的失败轮换，真实事务回滚且原会话整行/哈希不变。运营不能普通退出，车主不能运营退出；运营退出严格空JSON/无查询。退出后旧、新access及新refresh均拒绝，另一车主仍正常访问。

额外以Barrier同步两线程刷新一份独立合成会话，实际结果恰一200一401；赢家JWT声明和签名有效，能读取车辆，退出后赢家/原access及赢家refresh全部401。并发阶段共7次额外HTTP（竞争2次、赢家访问1、退出1、失效检查3），不计入Newman主旅程45请求。
