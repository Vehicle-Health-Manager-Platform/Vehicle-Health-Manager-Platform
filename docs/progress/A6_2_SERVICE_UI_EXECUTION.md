# A6.2 防护、报工与质检页面执行记录

日期：2026-10-08。分支 `codex/a6-service-ui`，直接依赖 `codex/a6-service-backend`（PR #42）。

## 已交付

- 商家订单入口与施工防护页：座椅套/方向盘套必选，一张防护照片，确认提交后只读；查看本店完整报工与质检签名。
- 技师本人工单入口：未防护阻断，已接单施工中才开放三类照片、方案、故障分析、配件名称/型号/品牌/数量、整数分钟工时；无故障件与未使用配件须明确声明。
- 完整报工提交后只读，仍处于施工中；独立手写签名板不接受空白/单点，PNG 导出、本人上传与质检确认，成功后显示待核销。
- 每类照片最多 9 张；只允许 JPEG/PNG、1–10 MiB。上传失败保留原图原键；图片访问按本店/本人订单重新获取短期 HTTPS 签名，不持久保存 URL。
- 页面隐藏、卸载、账号变更后拒绝迟到回调；导出超时恢复按钮；修改笔画清除先前上传签名。确认弹窗复核当前身份、页面和原请求内容。

## gstack H5 实际交互

使用 gstack `/browse`，390×844 窗口，合成身份接真实 A6 后端、隔离 MySQL、MinIO 与官方 ClamAV；没有业务响应替身。隔离库应用 V014 前已备份，重复应用通过。登录会话来自本地测试桥接，调用真实车主确认、派工和本人接单作为前置。

1. 未登录显示技师登录入口；合成技师进入本人施工订单，缺防护时不显示报工表单。
2. 商家选择两项必备防护，H5 原生文件输入填充合成 PNG，保留原生上传；上传完成后二次确认，防护不可修改。
3. 技师上传施工/完工照，明确声明无故障件和未使用配件，填写方案、分析和 35 分钟；确认提交后显示只读完整报工，状态仍为 IN_SERVICE。
4. 空白签名提示禁止提交；对实际 canvas 分发连续鼠标笔画，经页面按钮原生导出 PNG、上传成功；截图可见画板和已上传 PNG 笔画一致。
5. 确认本人质检签字后显示 SIGNED 与 PENDING_VERIFY；商家只读查看同一施工记录及签字时间。
6. 防护页与签名板没有横向溢出；浏览器无应用运行错误（只有既有路由弃用、无界面文件选择器和 canvas 性能提示）。

H5 请求使用只监听回环的传输桥接解决跨域；桥接只转发真实 HTTP/multipart。无界面浏览器不会拍摄物理照片，测试仅抑制系统选择器并填充合成 PNG。截图保存在被忽略的 `.cache`，不上传会话/配置。**没有把短期 URL 的申请成功等同于自签证书直连图片预览通过**。
