## 证据与交付边界

实际请求的方法、路径、查询、身份、状态与断言必须符合清单；签名回调检查实际正文 HMAC，正常/重放必须发送相同字节和签名。最终核对订单、支付事件、接车、派工、防护、报工、核销、归档任务/记录均唯一，其他用户/门店不得产生订单，真实支付必须未配置。

JWT、预约码、签名与环境文件仅在忽略目录 .cache；仅提交脱敏汇总。合成文件元数据不证明上传/扫描、真实图片存储或实际识别成功。LOCAL_TEST 不代表微信扣款、正式核销结算或真实账号激活。全部 API 验收仍未完成，性能延迟未达标仍保留。
