# R8b3c2 只读价格比较执行

2026-10-17。沿[已确认设计](R8B3C2_PRICE_COMPARISON_DESIGN.md)实施，无新增业务规则待确认。无新迁移，仍 V056/116 表；全 R8 完成前保留本地。

## 已实现

- 两个独立价格权限 GET 接口：固定 20 分页和报价详情。单只读 REPEATABLE_READ 事务、一个观察时点、严格选择器及 no-store。
- 有效上架报价与仍发布失效报价的去重候选。有效发布依据优先，其余草稿/停止仅作说明；来源、发布凭证、窗口或版本不足明确 UNKNOWN，不使用默认区间。
- BigDecimal 精确比较，两端含边界；低/高仅需核对。显示当前来源、原报价/依据版本、单位/适用说明/窗口和最小原因，无改价/处罚或业务写副作用。
- 原报价保存审计和发布状态审计须未软删除且为最新相关事件。删除最新报价版本或停止后恢复旧发布行均不能回退采用旧证据。
- 当前 comparison_available=true，c1 的永久原创建回执保持原 false；标志不参与冻结业务证据，客户端兼容但必须重新读取实际比较。
- 实际列表/详情两页、共享结果组件、运营与配置入口、精确登录回跳；草稿与已冻结依据文案区分。切号/失权/隐藏/换详情清理旧结果，丢弃迟到响应。
- [API](../api/PRICE_COMPARISONS.md)、[运维](../operations/PRICE_COMPARISONS.md)及 OpenAPI 生成器已同步，300 操作/1044 已解析引用、99 路由/56 挂载。
