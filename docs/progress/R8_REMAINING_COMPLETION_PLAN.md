1. **R8c1b3b公开问答页面**：复用既有八API，严格DTO、完整脱敏预览和另行确认、本人申请及撤回、受限运营审核、同款读取/UUID引用；持久原请求按角色/账号/业务隔离，创建可永久恢复，其他操作保留安全窗口；切号、选车、隐藏和权限变化拒绝迟到显示。补行为测试和微信/H5构建。
2. **R8c2图片治理**：明确选中本人已有私有图片与独立上传的脱敏副本，绑定当前源指纹及父公开内容；只展示通过扫描、独立授权且审核通过的副本；原件不公开、不复用原件签名URL。逐图申请/最小预览/审核/撤回，父内容撤回、来源/车辆/权限失效后拒绝新读取。已交付字节不能声称被远程删除。暂不引入识别供应商或自动隐私识别。
3. **R8c3许可资料与检索**：独立受限运营治理、结构化资料正文、授权依据与许可确认、版本、精确车型与有效期；草稿/发布冻结/停止及原请求恢复。车主本人车型下检索，仅返回当前可用资料与可追溯引用；AI仅使用重新核验后的公开专业资料片段，不把私有历史混入检索。无资料/未配置明确未知，禁止虚构语料、许可或引用。原文建议的Milvus向量效果因暂无嵌入服务/授权语料单独列外部验收，不以关键词检索冒充向量完成。
4. **整R8收口**：逐项需求核对、来源/权限/状态/并发/回滚/恢复测试、前端及微信/H5/历史Web、实际迁移/Compose、OpenAPI与原基线检查；整理API、运维、执行、验收和当前进度。全部剩余功能完成后统一上传完整代码和文档，按既有用户授权合并，保留R9与外部验收边界。
