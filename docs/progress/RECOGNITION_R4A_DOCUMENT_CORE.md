## 已完成

- 固定PDFBox3.0.5私有CLI，复用现有静态PDF校验。原生页提取文字并记录精确页内UTF16偏移；XObject、内联图片、绘图内容或无文字非空页栅格化OCR，避免只读页脚漏掉视觉主体。空白无内容页不加载OCR。
- 内部JPEG/PNG及PDF统一候选协议，绑定原字节SHA-256，原生可信度null；OCR位置/分数来自实际Paddle rec_polys/rec_scores，核对页号、文字区间、有限凸多边形、范围与栅格大小，不伪造位置/百分比或维修事实。
- 4页/80块/总4096 UTF16/每块500单元预算，栅格最长2048/400万像素/4MiB；超限整次失败，不截断成功。PDF上传最多50页不等于内核接受50页。
- 独立子进程、Java256MiB堆/25秒及整体60秒截止，父退出绑定和进程组清理；子进程环境白名单不带凭据/Java选项。容器非root、只读资源、无网络/端口、2GiB/CPU2/PID128/受限tmpfs，严格socket禁止不放宽。
- 运行器仅复制必要Java类和7个PDFBox/Jackson依赖并记录摘要，排除应用配置；仅COPY当前.py源码，禁用宿主字节码缓存。既有mileage/license私有HTTP场景未增加document入口。统一交付入口新增第11组并绑定本目录源码。

## 修复与CI边界

1. 缓存OCR镜像缺当前license_fields模块；验收镜像复制完整当前Python源码，不依赖旧镜像业务代码。进一步只复制.py并固定空的临时pycache前缀/禁写，避免宿主字节码与源码摘要脱节。
2. 实测发现JDK NIO文件通道及ImageIO默认磁盘缓存会创建socketpair，撞上严格网络禁止；改为普通文件流并仅在私有JVM关闭ImageIO磁盘缓存，未放宽seccomp。最终扫描、混合与旋转实测通过。
3. 增加内联图片/绘图页保护、确切位置和类型/预算/源hash校验，异常模型行不返回部分成功。
4. Windows模型目录发布测试在注入一次共享拒绝后还可能遇到真实短暂拒绝，原断言固定2次导致偶发误报。改为验证2至4次有界重试、等待次数对应并实际校验发布目录；持久拒绝/禁止部分发布测试保留，最终OCR全组通过。
5. PR247后端CI最终在覆盖审计失败：显式真实ASR套件默认7项跳过，严格门禁拒绝。普通core-coverage配置现在仅排除该非必需显式资源套件，不改覆盖率门禁/阈值；必需核心套件不得被排除有回归保护。真实Maven profile探针运行普通6项、零跳过且无真实ASR报告，独立真实ASR运行入口保持原显式选择。不是当前全后端/覆盖率或新head CI已通过。

初轮统一回归OCR这一偶发断言失败已保留为历史日志，由修正后的最终完整11组取代。自动审批超时未执行的验证允许重试后完成，不把未执行计为失败/成功业务证据。
