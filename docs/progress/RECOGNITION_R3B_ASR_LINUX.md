## 测试与修复

最终真实运行17项检查全部通过，执行前后源码一致。英文样本由本机Microsoft Zira Desktop en-US合成：The engine makes a noise. Please check the brakes. 实际模型返回两段对应文字，耗时11.862秒；3.096秒数字静音返回EMPTY，耗时7.168秒。每次请求重新加载模型，时间包含子进程启动与模型加载；这些不是500并发/稳态性能结论。容器累计峰值内存861888512字节，约822MiB；不是内存压力或OOM验收。

实际首轮发现数字静音被Whisper输出“You”。修复为解码后仅对全部采样值为零的数字静音返回EMPTY，不设置会删除轻声的幅度阈值。增加零能量无幻觉回归；原适配测试改用极低非零采样，仍进入模型以覆盖轻声不误删。最终实际静音及英文模型回归通过；其他背景噪声/无语音幻觉仍待评估。

首次整文件模型下载读超时，改为固定版本分段重试，最终模型LFS摘要一致；正式准备工具已采用分段限次重试并经完整重新下载验证。下载失败时临时资源不发布，不降低TLS或hash校验。

最终统一10组通过且源码摘要一致：小程序1189、Python546、ASR36、OCR76通过/1平台跳过，微信与H5构建、普通微信无测试身份桥/共享样式、OpenAPI、迁移挂载、交接和契约结论检查通过。新增5项验收工具测试包含资源/权限配置逐项绕过拒绝；ASR36项包含9项资源工具及1项静音新增回归。早期默认沙箱回环/子进程测试未完成，停止后在获准环境运行成功，不算默认环境通过。
