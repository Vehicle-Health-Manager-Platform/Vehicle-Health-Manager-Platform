### 5.2 真实环境与专项验收

已有本机真实后端/数据库及辅助 H5 交互记录，但以下仍没有完整验收结论：

1. 当前阶段微信开发者工具原生页面的自动化连接与完整履约流程：导入/CLI auto 成功不等于模拟器 WebSocket 已连接或操作通过。
2. iOS / Android 真机的三角色登录、手机号绑定、相机/相册授权、上传、可信 HTTPS 图片预览、手写签字及弱网恢复。
3. 商家/运营正式短信供应商接入与收发；目前发送适配器未形成生产实现，缺配置会拒绝请求。
4. 正式微信支付/退款和真实资金对账；本地测试支付不可用作线上收款验收。
5. 原文性能门禁：核心读接口 P95 < 300ms、P99 < 800ms，写接口 P95 < 500ms；500 并发错误率 < 0.1%，慢 SQL 优化证据。
6. 原文核心方法覆盖率 ≥70% 的测量结果；当前 CI 单元/集成测试通过，不等于覆盖率已达标。
7. 安全专项扫描结果、上传攻击样本与全功能权限矩阵报告；已有归属、限流、文件校验和审计测试，但未见全范围扫描/上线安全结论。
