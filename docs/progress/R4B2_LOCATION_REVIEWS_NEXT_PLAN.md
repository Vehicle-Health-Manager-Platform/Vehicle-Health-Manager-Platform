## R4b2a 先做位置与距离

1. 盘点现有门店可维护lng/lat、入驻区域和微信定位权限；冻结坐标系、维护者/来源、是否可用于距离计算及缺失规则。不能假设旧坐标与微信定位同一坐标系，不从地址或行政区划中心猜门店位置。
2. 微信仅在车主主动选择附近时请求定位；拒绝/超时/不可用保留手选区域与价格排序。位置只用于当次请求，未有明确用途不持久化车主精确位置或放进日志/审计。
3. 后端仅可信且坐标系兼容的门店参与距离计算/排序；无坐标/来源不清显示距离未知，明确是否含未知行及稳定分页规则。距离是直线距离，不能称驾车路线或预计到达时间；详情和列表口径一致。
4. 校验坐标边界、同点/缺失/坐标系不符/稳定分页、权限与停用，微信定位取消/地区回退/生命周期/原生构建；中文文档与分阶段PR、最新六项CI。真机定位独立验收。
