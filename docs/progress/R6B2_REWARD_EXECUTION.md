# R6b2：资格快照与邀请奖励交付

状态：本地实施及边界修复验证完成；整 R6 完成后统一上传代码、迁移、测试和文档。

## 已确认范围

- 车主每个有效邀请事件双方各一券；员工推广只给新客一券。模板可跨事件复用。
- 公共领取仍为每人每模板一次，邀请发券使用独立来源及事件唯一键。
- 资格确认事务冻结当时有效的已发布政策、券版本、原始有效期和受益人。停止政策不撤销已冻结资格。
- 未配置政策冻结为 UNKNOWN_POLICY，历史资格缺少快照也显示未知；不得用后来发布的政策追溯补发。
- 发券由后台任务完成，GET 只读。车主双方同一事务到账，缺库存不先发一方。
- 原始券过期进入 EXPIRED；账号不可用、来源停用、库存不足分别等待恢复，不替换券、不延长有效期。
- 后台每次事务重新验证资格及冻结来源。审计、库存、两方持券、来源凭证和任务完成一起提交。
- 正式身份与奖励后台开关默认关闭，隔离合成 MySQL 测试验证实际执行路径；正式身份接入留至 R9。

R6b3 的分享载体、首页提示、来源配置解锁和整阶段验收另行完成；本步骤不上传 GitHub。
