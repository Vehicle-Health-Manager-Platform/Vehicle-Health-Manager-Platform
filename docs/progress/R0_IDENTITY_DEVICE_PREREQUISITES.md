# R0 正式身份与真机实施前置清单

日期：2026-10-10。只用于微信小程序交付，不包含 PC 运营后台。

## 下一单元：R0.2 正式短信与员工绑定

当前 `MerchantSmsSender`、`OperatorSmsSender` 只有发送契约，正式供应商适配尚缺。商家与运营验证码入口在 sender 未配置时返回 503；不得加入固定验证码或使用合成 OTP 作为正式登录通过。

| 需要落实 | 提供方式及用途 |
| --- | --- |
| 短信供应商、地域/接口 | 确认供应商后实现同一服务端适配器，分别绑定两个 sender 契约 |
| 已审核签名/模板及验证码参数名 | 核对与本项目五分钟登录码一致，不能推测模板内容 |
| 服务端凭据和授权测试手机号 | 仅通过受控服务端配置注入，不写仓库、PR、截图或前端 |
| 商家/运营测试账号权限 | 在受控环境按既有离线工具准备；正式短信只发获授权手机号 |
| 微信员工身份和门店绑定 | 用实际微信账号完成本人绑定/接单及跨店权限验证；不复用合成身份桥 |

实现验收：发送成功、供应商失败不发放可消费码、限流、五分钟过期、一次性消费、错误码/重放、退出和撤销即时生效；页面真实登录及权限变化。正式配置未提供前先完成适配设计与错误映射，发送环节保持未完成。

## R0.3 手机真机及正式网络

- 确认获授权的 iOS/Android 设备、微信账号、合法域名/AppID 和客户端体验权限。
- 配置有效公网 HTTPS 证书及可达对象下载地址；不能把回环、自签证书或开发者工具 URL 例外作为手机网络验收。
- 实际相机/相册选择、用户取消、权限拒绝/重新授权、上传/扫描、手写 PNG、私有图片加载和关闭预览逐项验收。
- 复测车主、商家、技师履约与独立运营登录/审核/撤回；系统确认/取消必须真实点击。
- 正式微信资金及退款独立资金规格，LOCAL_TEST 始终标注未真实扣款。
