## 验收设计

- 结构化维护/清空保留revision，保险起止日期与年检字段，写回执及审计不含私有字段值。
- 六指标空列表不显示正常；OIL记录、修正、显式替换来源、清空、拒绝连续清空，历史倒序游标与修正链保留。CELSIUS负值、PERCENT上限与未来日期边界。
- 合成车型OIL规则，未配置UNKNOWN、本人确认前不可使用、确认后单项参考值而整体仍UNKNOWN/无整体分；撤销确认后旧回执不恢复确认，修正/来源变更使确认失效，撤回规则后旧回执不恢复规则。未配置其余指标不猜测适用性，不生成必做项目。
- 提醒NOT_SET、里程到达DUE、未来PLANNED、明确提前偏好UPCOMING、停用INACTIVE，保险与年检只接收日期。旧版本与跨车主/角色拒绝，另一车主保持未设置。

每项操作均检查正常/边界/错误/未授权、no-store与JSON信封。实际令牌身份、方法、来源路由和完整query均纳入证据审计。新 --health-cases 与既有套件互斥，每次新库；源码哈希稳定，匿名请求前后131表不变化，数据库最终行数/修订/私密审计与本次容器/网络清理均为门禁。

## 边界

合成规则数值仅用来验证协议，不是生产阈值、诊断建议或官方核验。EXPERIENCE_PUBLICATION_ENABLED=false、KNOWLEDGE_AI_ENABLED=false；没有真实微信/支付/外部识别/通知调用。仅验证本地提醒状态，不代表微信消息已送达。原始JWT、环境和私有响应只留.cache，提交脱敏汇总。

本阶段修复三组车主控制器忽略未知/重复查询参数的问题，覆盖只读选择器和禁止query的写接口；新增公共轻量校验及4项HTTP回归，交付验收资产、运行器/CI接入及文档。全量352接口业务验收和性能延迟达标仍未完成。
