## 实施范围

2026-10-19：现金券领取→预占→取消释放→支付消费→退款申请/同意/失败不返券→成功返原券→重新预占/释放；独立 SERVICE 券授权→门店预览→核销。新增 20 接口、160 请求/547 断言，每项均含正常、边界、错误、未授权类别。
