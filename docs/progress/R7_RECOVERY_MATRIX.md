# R7 恢复与登录边界

本说明覆盖源码实际行为；验收与环境限制见[统一验收](../testing/LOCAL_R7_COMPLETION_ACCEPTANCE.md)。未配置来源显示未知，正式短信/微信/资金和真机仍R9。

## 身份、隐藏与回跳

- 角色登录页只向紧邻的、精确白名单中的业务页面返回，并检查角色、有效编号；运营还检查本次登录的诊断处理/管理权限。失败回固定合法落点，不接受任意URL。页面返回后重新查询服务器权限。
- 车主/技师账号ID先于token更新。恢复键含账号及订单或诊断范围；切号、页面隐藏、失权和迟到响应不能继续展示旧正文/图片或提交旧身份请求。登录凭据只存内存。
- 401保留尚未明确失败的本机原请求，同账号重新认证后先授权再恢复；403/404等明确失权清理相应本机范围。存储失败阻止新发送，清理失败阻止新请求。设备上的草稿不是云端同步。

## 显式草稿和持久原请求

- 诊断新留言、本人追问/关闭、当前处理人回复/关闭：七天显式文字草稿；确认后持久保存不可变正文、业务编号和原键。创建另有永久submission_key/hash，通用回执到期仍不得重复建诊断。追问/回复通过期望版本，关闭通过当前状态复核。恢复不重新选择车辆、政策、内容或新键。
- 技师施工：七天显式方案/分析/工时/配件草稿；不保存照片、签名位图、临时路径或私有URL。确认过的原请求只保留原正文及原文件编号/键。读取当前已接单工单及施工事实后，报工全字段匹配或原签名文件匹配可确认已成功；不匹配拒绝冒认，未执行且状态允许才重试。签字原文件若已不可用，服务器拒绝，不偷偷换图。
- 诊断受理配置：账号隔离的创建/修订/状态原请求。通用回执24小时；客户端23小时后禁止重发，每次重试均检查窗口，停留页面也不绕过。用户重新授权、读取服务器配置并明确核对后可清理本机未决记录；比较原存储记录防止清除另一页面新请求。清理不会删除服务器配置，不会自动再创建。
- 多页面保存和完成均比较当前未决记录，不能覆盖其他正文或清除不同未决请求。草稿只由用户显式保存，不因浏览页面自动把敏感正文落盘。

## 当前服务器事实与版本恢复

- 档案逐条授权/撤销：先重新读取本单有效授权和源指纹，写入带期望版本；源变更或撤权不能靠旧版本覆盖。当前门店/接单技师还需每次授权读取及文件签名复核。
- 诊断分配：管理队列只含最小状态，当前版本和有效处理人限制并发修改；刷新确认当前分配，不从旧队列提升为正文权限。关闭重新读取当前状态，不能把冲突当成功。
- 消息已读：订单及诊断分别保留同页面原键；业务唯一消息和首次read_at让新键也只确认同一已读事实。读取和回执都复核当前接收用途，失权后拒绝。
- 旧履约写：共享流程在当前页面冻结正文、身份与键，未知时改表单或改派工目标不会产生第二请求；页面提供“重试原请求”。这些旧流程的原键不跨重启持久化，离开后按当前服务器订单/派工/时段/报工事实及已有版本、状态或唯一约束恢复，界面不能宣称自动重放。
- 预约、支付/退款、券核销沿用既有服务器创建意图、冻结/消费/返还唯一流水和状态机；实际渠道未接入时仍是LOCAL/TEST，不将重试按钮当成正式资金验收。

## 事件可靠性

17类订单事件及5类诊断事件与业务同事务，来源及接收目标唯一。独立投递任务逐事件原子扇出，支持多消费者锁、失败退避与重启恢复。浏览页面不制造业务事件；无历史回填，不从旧无来源消息反推授权。通知只给当前合法入口，详情仍二次授权。
