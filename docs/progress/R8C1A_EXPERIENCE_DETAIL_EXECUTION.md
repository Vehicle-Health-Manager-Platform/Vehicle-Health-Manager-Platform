## 已实现

- 新增 OWNER 单条 GET，以当前本人 vehicle_id 和随机公开 UUID 查询，响应绑定接收车辆及原五字段获批摘要，严格选择器、no-store、不可用404/关闭503。
- 列表/详情共用当前来源判断及可信施工校验；接收者、原作者和车辆关系、有效同款车型/车系/品牌、原授权/审核修订/非测试来源逐次复核。批准时也要求当前目录启用。
- 撤回后旧 UUID 失效，重新授权/批准产生新入口；源变化、目录停用、车辆转移/删除或原作者失效停止新读取。读取不写热度/积分/审计等事件。
- 现有同款经验页内详情面板、重新核验与只含公开 UUID 的可复制应用内入口；AI 方案获批摘要导航至同一入口。没有私有图片、身份或档案复制。
- 登录精确返回、当前车辆/车型/引用与 DTO 绑定；切号、换车、隐藏和迟到响应清理。列表确认会话或车辆失效同步清详情，详情404移除对应旧列表项，手动刷新同时重验列表和引用。
- [协议](../api/EXPERIENCE_DETAIL.md)、[操作](../operations/EXPERIENCE_DETAIL.md)、OpenAPI及既有经验说明同步；原列表/方案 DTO 和游标保留。
