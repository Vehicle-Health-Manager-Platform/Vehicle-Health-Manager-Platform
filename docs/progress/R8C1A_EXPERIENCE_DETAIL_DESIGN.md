# R8c1a 受控同款经验详情设计

2026-10-17。用户已要求按上一阶段下一步计划开始实施，沿已确认的经验授权、审核、撤回和最小公开字段，无新增公开用途。整 R8 完成前不上传。

采用共用有效来源查询的只读详情：保持现有五字段公开摘要，新增 GET `/api/community/experiences/{id}?vehicle_id=...`，id 为随机公开 UUID，响应 `{vehicle_id,experience}`。列表、详情、AI 方案引用均核对当前接收者/本人车辆/有效同款车型、原作者/车辆当前关系、授权/审核修订及可信施工来源。车型/车系/品牌停用也不再展示。无效详情统一404，发布开关关闭503；原列表关闭时仍空列表。

两个替代方案是复制一份详情表或直接按私有卡片编号读取：前者增加撤回一致性成本，后者暴露私有来源选择器。采用复用当前获批投影，仅重构本次必要的查询与投影，不扩大原字段和用途。

沿现有同款经验页增加单条详情面板。应用内引用只含公开UUID，可复制或由AI方案摘要进入；不包含接收者车辆编号或原作者标识。接收者登录后自行选择本人车辆，每次重新读取，不将入口当授权。前端严格核对车辆、公开编号、车型和响应结构；隐藏、切号、换车/车型/引用时清空旧结果并丢弃迟到响应。

本步无新迁移或权限，不增加公开图片、热度、问答、点赞评论、自由编辑器或官方分享。原列表和方案证据形状保留；验证真实源变更、撤回后重授权旧UUID失效、跨车主/车型、目录停用、会话撤销和读取无副作用，再整理API/操作/执行/验收。后续热门依据及问答处理规则在R8c1b盘点后集中确认。
