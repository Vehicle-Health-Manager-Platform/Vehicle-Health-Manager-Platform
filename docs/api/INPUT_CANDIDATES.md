# A3候选确认与适配边界

本阶段仅新增小程序本地候选状态与表单接入，无新增HTTP/SQL。沿用352操作、131表、62迁移挂载。真实ASR/OCR/多模态仍B2，当前没有可返回合成识别结果的业务端点。

## 场景与正式写入

- vehicle：车牌、VIN、仪表盘里程，仅带入新车手动登记；不解码或修改车型，原车辆保存仍add_type=4。
- archive：标题、备注/人工语音整理、历史里程、发生日期；原档案保存仍manual/photo，不标记input_type=2，不修改车辆登记里程或健康读数。
- license：行驶证结构化页现有文本、日期、整数项，复用原字段表及revision；不自动勾选owner_confirmed，原本人来源核对仍必需。质量、浮点重量等其他字段继续原表单手填。
- voice：本人对录音材料手动整理的问题，只带入AI草稿；原发送仍文本API，不附材料ID、路径或音频。

原有输入不被静默清空。候选空项不覆盖现值；候选全部通过格式校验、显示对照并勾选逐项核对后才可带入。带入不是数据库确认，原保存/发送继续执行原权限、幂等、乐观版本和业务校验。

## 本地状态

closed → editing → review → applied；任何修改回editing并取消核对。recognizing仅供未来可替换适配器/隔离测试，默认unavailableRecognition返回UNAVAILABLE。生产页面展示未配置及手动整理，不发送识别请求。

候选只驻留当前页面内存，来源MANUAL或PROVIDER；手动整理明确未机器识别。场景、账号、车辆/档案范围、记录版本和原候选字段快照参与隔离；切换/隐藏/取消使异步结果失效。正在保存时不能确认；原表单变化需取消后重新整理。车辆车型切换清除候选，AI换车清空原草稿，避免携带上一辆车的问题。

## 识别结果边界（尚未连接供应商）

未来适配器的调用形式为 `adapter({scene,signal})`，返回Promise。调用实现应在服务端接入识别供应商；不能将密钥或任意外部URL暴露给小程序。material_id、当前正式身份/归属、场景与用途须在服务端独立验证，当前本地signal不替代服务端任务取消/鉴权。

结果严格为 `{version:1,scene,status,fields}`。status仅CANDIDATE/EMPTY/UNAVAILABLE；后两者fields为空。CANDIDATE至少1项、最多min(20,场景字段数)，每项严格为 `{key,value,confidence}`：key为本场景白名单，无重复；value为非空字符串，按字段约束验证；confidence为null或0–1有限数。拒绝多余属性、错误场景/版本/字段/类型和非法内容，不自动截断或猜测。低/未知可信内容始终需要人工确认；置信度不能作为官方核验。

请求默认15秒本地超时；取消/隐藏会发出取消信号，并隔离不配合取消的迟到结果。供应商异常只显示固定提示，不回显文件、URL或原始错误；空/异常/不可用/超时回退人工整理。B2接入时还需正式任务来源、材料绑定和模型准确率/隐私授权验收，A3本地测试不证明这些已完成。
