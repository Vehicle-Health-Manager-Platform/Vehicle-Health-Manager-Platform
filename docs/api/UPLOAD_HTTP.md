# 车主私有图片 HTTP 接口

> 2026-10-04。配套设计见 [HTTP 上传设计](../superpowers/specs/2026-10-04-upload-http-design.md)。真实私有部署与小程序图片操作尚未联调。

## 前置条件

数据库按顺序应用 V001–V004；新建 Compose 数据卷自动执行，已有库须人工补 V004。使用正式车主 user/OWNER 会话，依赖身份与退出撤销表。配置 [真实上传适配器](UPLOAD_ADAPTERS.md)的专用私有桶、扫描器、官方病毒库与私有凭据。缺少数据库或扫描/存储依赖时返回 503；local 演示令牌、绑定凭证和员工角色被拒绝。

## 上传

`POST /api/file/upload`，请求携带 Bearer 车主令牌、UUID `Idempotency-Key` 和 multipart/form-data 单个 `file` 字段。不能添加 owner_id、业务字段、重复文件或客户端对象键。

文件上限 10 MiB，总请求上限 11 MiB；允许 jpg/jpeg/png/webp，校验扩展名与格式标识。格式标识验证不等于完整图片解码。客户端 Content-Type 不作为可信类型；不保留原名。

成功 HTTP 200，统一响应的 data 为 `file_id`、`content_type`、`size_bytes`。同键、同主体、同字节与检测类型，在成功后的 24 小时内重放固定成功信封，仍复核会话/资源状态；不同文件返回 409，正在处理返回 409 + Retry-After: 2。改名不改变幂等指纹。未知提交/依赖故障返回 503，网络失败后使用同键同图片重试，不自动换键。

## 短时访问

`GET /api/file/{id}/access`，携带同一车主 Bearer 令牌。仅本人、未删除、CLEAN 文件可签名，还复核桶私有策略、对象大小与 MIME。成功 data 为 `url`、ISO 时间 `expires_at`；响应 Cache-Control: no-store，每次重新生成，不在幂等结果或审计中保存 URL。默认 120 秒，可配置 1–300 秒。已签 URL 在 TTL 内可能仍有效，即使会话被撤销或权限改变。

## 安全错误

| HTTP / 业务码 | 含义 |
| --- | --- |
| 400 / 40001 | 字段、文件或 UUID 无效 |
| 401 / 40100 | 无会话或已失效 |
| 403 / 40300 | 非正式车主会话 |
| 404 / 40400 | 文件不存在、已删除或非本人 |
| 409 / 40900 | 幂等冲突、处理中或文件尚不可读 |
| 413 / 41300 | 单文件或总请求超限 |
| 422 / 42200 | 病毒扫描拒绝 |
| 429 / 42900 | 每分钟上传 10 次/签名 60 次，或每实例上传并发已满；附 Retry-After |
| 503 / 50300 | 依赖不可用、结果待核对或失败清理中 |

限流计数存数据库，独立 file_upload/file_access scope，不更改身份绑定限流。并发上限默认每实例 4，通过 UPLOAD_HTTP_CONCURRENCY 配置正整数；不是集群总额度。入口保护在 multipart 解析前执行，解析总大小/单文件上限同时约束 chunked 请求。Nginx 上传路由同步限制 11 MiB。

## 失败与核对

上传先在短数据库事务保留随机对象键与尝试，事务外扫描及 PUT，再原子提交 file_object、成功响应、成功审计与上传成功状态。不在已有 WriteIntegrityService 事务中执行扫描或存储。

失败或提交结果不确定时先查上传记录，已提交则复核权限后恢复结果；只有确认失败尝试已被终止且没有对应文件记录，才执行清理。超过五分钟的 PROCESSING 被终止并登记核对；旧 attempt_id 不得提交。

默认每 60 秒轮询（UPLOAD_CLEANUP_INTERVAL_MS），每轮最多 100 条。数据库认领避免正常情况下重复任务，重试退避上限 1 小时。清理后保留对象键墓碑并每小时复核迟到外部写入；当前不自动清除墓碑。永久故障保留任务并记录安全事件 upload_reconciliation_pending，需运维排查配置、积压及存储容量。

MySQL 与 MinIO 不是分布式原子事务，可能暂时存在孤儿对象或待核对状态；不承诺绝对无孤儿对象。只清理协议登记的失败键，不扫描全桶、不删除已成功但尚未关联业务的文件。未关联文件的后续生命周期随 S1 契约定义。此接口不等于车辆档案已创建。

## 验证

新增实际嵌入式 HTTP multipart、MySQL 状态/审计/并发/故障测试，并用真实 MinIO/ClamAV 适配器执行上传、重放及签名下载。CI 使用合成病毒签名，不证明生产官方病毒库覆盖率。完整结果见对应 PR CI 和 [执行记录](../progress/S0_EXECUTION_LOG.md)；本机没有 Java/Maven 和可运行 Docker 时，后端测试以 CI 为证据。
