# How to 在技师端接单、报工与质检签字

2026-10-29复核：下述业务步骤仍适用。本地合成身份下接单、施工、签字、核销后的三角色状态已按[阶段报告](../testing/STAGE_ACCEPTANCE_2026_10_29.md)分层验证。相机、扫码、微信绑定及手机后台恢复仍须按[外部接入](../delivery/EXTERNAL_INTEGRATIONS.md)补充实际证据。

适用2026-10-23当前微信小程序源码版本。在初始页选择“技师端”，用微信身份绑定门店签发的一次性员工码。过期/撤销的员工码需店长重新签发；不能使用商家或车主会话代替本人身份。正式微信绑定和手机端采集仍待验。

1. 登录绑定后进入“我的工单”或当前任务工作台，核对门店、车辆和本单项目，再本人接单。订单详情为 `pages/technician/order-detail`。
2. 确认本单已接车且车主确认、有效派工仍属于本人。异议、转派、解绑或停用可能阻止继续施工，先刷新核对。
3. 查看本单必要资料与车主授权档案，仅使用当前可读资料。授权失效后请车主重新确认，不能沿用旧图片链接。
4. 在 `pages/technician/work` 记录过程、故障件和完工照片，完成必要上传。没有故障件/没有使用配件时用对应明确声明；不要上传无关照片充数。缺防护证据先由商家补齐。
5. 填写施工方案、故障分析、实际配件及工时。配件数量为1–999，工时为1–1440整数分钟；核对后点击“确认提交完整报工”。
6. 报工保存后完成本人质检签名，检查签名图片已上传，再点“确认本人质检签字，送待核销”。签字成功后记录锁定；商家根据车主核销码完成最终核销。

## 验证与排错

刷新后应看到已提交的报工、照片数量、实际工时和签字时间。报工提交与签字是两步；仅选取本地图片不等于已上传或已提交。网络异常优先“核对后重试原施工请求”；不要编辑另一份内容冒充原请求重试。相机失败按提示开启相机权限；归属或绑定失效重新登录/绑定并核对派工，不能继续使用旧页面写入。

## ASR转写边界（R3）

R3 ASR任务不授予技师读取车主音频或转写的权限，不能以材料ID跨车辆/用途访问；原报工和历史档案授权继续独立执行。 [操作、状态与接入](../api/ASR_JOBS.md)。真实ASR/声音效果与手机仍待验。
