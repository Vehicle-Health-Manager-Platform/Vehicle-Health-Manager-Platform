# How to 在商家端接车、派工并交付服务

适用2026-10-23当前微信小程序源码版本。从初始页选“商家端”，使用账号、密码及短信验证码登录。店长/店员权限不同；待激活账号不能由客户端绕过。正式短信和真实入驻/激活闭环仍待验。

## 接车与派工

1. 登录后进入本店订单，核对车主提供的预约码和本店订单。在订单详情进入“接车检查”，记录环车照片、仪表/油量、里程及损伤。
2. 提交后请车主在本人接车单确认。车主提出异议时处理并记录，再等待车主复核；未确认或异议未解除时不能派工。
3. 进入 `pages/merchant/dispatch`，按本单有效员工分派技师。技师需本人接单；更换派工后旧技师不应继续操作。
4. 在施工防护页保存必需防护照片；缺少有效防护证据会阻止后续报工。

## 施工与核销

1. 用本店服务工作台按当前分类进入订单，读取本单必要资料及车主已授权档案；没有授权不能读取全部历史。[工作台与授权](../operations/SERVICE_WORKSPACE.md)。
2. 跟踪技师施工照片、报工和质检签字；商家不代替技师本人提交质检签名。
3. 待核销前检查取车对比，再让车主提供六位核销码，在“核销验码”提交。核销后刷新本店订单查看可信记录；测试核销不代表真实付款。
4. 取消/退款从订单的对应入口办理，按当前状态及双方同意处理；正式微信退款待接入。恢复查询显示异常时核对原事实，不手工改成已退款。

## 门店管理

在角色入口管理本店服务、时段、员工、资料和佣金账单。只有相应权限账号能修改；店长创建员工及签发/轮换员工码的规则见[员工运维](../operations/STORE_ACCOUNTS.md)。服务上下架不应改写历史订单价格快照。

券发行与服务券独立核销见[券说明](COUPONS.md)。本店经营看板、客户关系及月度考核均受本店归属约束；未知指标不能当零。佣金账本不等于实际结算到账。

## 验证与排错

每次操作后刷新本单状态，确认技师、车主确认及核销事实一致。无权限先核对账号职责；资源不存在也可能是归属被隐藏，不要尝试其他门店ID。功能未开启联系管理员核对开关，不能靠重复点击开启。网络失败使用原请求重试，版本冲突重新读取；相机/上传失败先核对权限、扫描和当前订单阶段。

# 接车里程识别补充（2026-10-26）

在接车检查页先上传“仪表盘”位置的本人照片，里程区即可选择该照片、同意识别用途并点击识别。结果仅为候选：对照原图检查或修正，点击检查候选内容、勾选已核对，再确认带入里程框。识别服务未启用、失败、歧义或超时时继续手工填写。

带入不等于保存。仍需八个位置的独立照片、预约码、油量/损伤、必要的回退或到店偏差原因，最后按原按钮提交；仍需车主确认才可派工。切账号、换图、离开或取消后旧候选失效；自行更改里程后旧候选不能覆盖新值。真实模型和手机效果另验，详见[接口与限制](../api/PICKUP_MILEAGE_RECOGNITION.md)。

行驶证新车识别属于OWNER入口，商家身份无权调用或读取车主图片。接车仪表里程仍走本店订单/当前员工图片的独立授权流程，不能套用新车接口或把行驶证照片当接车证据。[行驶证边界](../api/LICENSE_RECOGNITION.md)。
