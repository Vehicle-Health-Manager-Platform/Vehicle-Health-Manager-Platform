# 邀请与员工推广使用说明

## 车主

在“我的 → 邀请记录与月度进度”登录后生成邀请码，复制给好友。好友通过“我的 → 输入好友邀请码”显式选择后进入车主登录；只在首次注册保存来源，已有账号不能补填或换码，登录会提示已有账号不增加人数。

未登录好友在“我的”的登录提示下点击“有好友邀请码，先填写再登录”，进入公开落地页后再授权；此入口不显示任何车主私有数据。不能先注册再补填归因。

注册后按登录页提示绑定微信手机号。页面显示自己的注册来源和资格结果：待确认、来源未知、测试、不符合或有效新客。当前正式资格确认默认未开放，未知和测试不会计入有效人数。邀请页不能代替新客证据。

每月按北京时间新增 1、2、3、4 人依次达成四档，累计节点 1/3/6/10；满10人重复。页面有效人数是当前月资格确认数，待确认/未知/测试/不符合为全部历史；上月注册但下月确认的有效资格计下月。翻页可查看历史记录，不显示好友手机号和身份资料。

网络失败可刷新读取；生成推广码失败用页面“重试生成”恢复原请求，不必重复新建。已受理的码同人换键也不会再生成。退出登录/切换账号后原显示清理；应用重新启动需再次明确邀请来源。

## 店长与店员

门店登录后通过“我的推广码与新客归因”查看本人推广源与冻结门店的记录/进度。此推广码与员工登录绑定码不同，不能用它登录或绑定员工。停用、撤销或转店后旧来源不能产生新客；不展示其他员工/其他门店的客户记录。

## 当前可用范围

R6 已实现来源、资格、月度进度、配置奖励、后台发券、奖励记录、本地海报与人工诊断资格。正式新客确认和奖励后台开关默认关闭，需完成正式身份验收及运营来源配置后启用。

邀请页“奖励记录”显示真实结果：待处理、等待库存、等待发行来源、等待账号、政策未知、已过期、证据失效或完成。只有完成表示本批奖励已发放；车主邀请双方各一次，员工推广仅新客获券。相同模板可以奖励不同有效邀请，公共领券仍每人每模板一次。新客登录后可查看自己的奖励及“我的券”；对方券编号不公开。没有政策时不会事后套用新政策补发。

点击“生成海报”绘制随机码与首次注册前输入方法，再点击“预览海报”在当前页面展开图片；预览不离开页面，也不保存到相册。“保存到相册”需另行点击和相册权限。切号或离页会清理临时图；若相册操作尚在进行，等待该操作结束后再删除临时文件，已保存相册图片不受影响。失败时仍可复制邀请码。正式微信小程序码和原生分享卡片在 R9 验证。

首页在有生效奖励政策或实际记录时提示真实进度和奖励状态。AI 页展示本月人工诊断邀请条件、来源、人数和截止时间；未配置显示未知，停用、到期、跨月或新客账号失效后重新判断。实际留言服务由 R7 提供，当前达到邀请条件不代表可以提交留言。
