# 健康、提醒与完整档案使用说明

## 运营配置

以具备目录权限的运营账号进入“标准目录 → 车型健康来源规则”。先选已发布的精确车型 ID 和指标，读取当前版本。根据实际手册/测量资料填写来源、核对日期、有效期、读数名称/单位/方法/来源口径、有效天数和分段权重；核对后勾选来源确认并发布。系统没有默认技术阈值。若有明确不适用依据，可发布“不适用”；撤回后车主重新显示未知。

技术必做另需填写标准项目和触发分数，并维护该项目/车型的有来源“适用”规则。来源不足先不配置。变更规则会令原车主确认失效，需要重新核对。生产手册和真实来源核验属于实际业务配置工作。

## 车主查看健康

选择本人车辆后，首页显示参考分、六类状态和五类提醒；进入健康页查看来源版本、有效期和原始读数。先从本人档案录入/抄录读数，再核对规则名称、单位和方法是否吻合，主动确认用于参考计算。缺规则、来源失效、过期、不匹配或尚未确认均显示未知。

全部适用项完成当前确认后才显示整车参考分。不适用项不加入权重，没有“未知=0分”。环形进度按真实分数绘制。趋势只连接同口径、连续有效的本人原始读数，展示日期/单位/变化量，不把变化直接解释为健康改善。修正/清空及过期断点保留在独立读数履历。

AI建议页可主动读取本车证据；来源规则触发的“必做”与模型建议分开，点击项目读取当前报价与时段，再核对预约。私有健康资料不会随该本地读取自动发给模型；问题用途仍需要单独确认。

## 档案与提醒

在本人档案选择保养、维修、保险、违章、年检、行驶证、驾驶证或故障，填写结构化资料。可保存未确认的部分信息；要触发故障/违章提醒，须完整填写来源和状态并勾选本人确认。处理违章或解除故障后录入最新状态与处理日期；新记录尚未确认时不继续展示同案号的旧警报。

行驶证/驾驶证/故障仅本人页面与私人报告可见，不进入限时分享摘要或自动AI上下文。此处是人工录入，不能核验官方证件或查询官方违章。本人确认后仍标注未官方核验。

从提醒入口设置本人保养/保险/年检目标，再到“提前提醒”选择提前天数/保养里程，默认0。保养可关联本人选定的标准项目，到期或进入提前范围后带到报价预约；项目停用/明确不适用则回服务选择。保险/年检回来源目标，故障/违章回本人记录。没有记录表示未知，不表示官方无问题。

## 搜索与门店选择

服务页可按目录关键词搜索；症状问题可带到AI建议页，需主动确认第三方用途才发送。门店报价可选价格、附近或公开星级排序；星级仅来自独立授权且当前合格的真实非测试履约记录，无有效样本显示暂无评分。新页面的真机交互与正式渠道效果留待 R9。
