# 小程序资金记录查询

运营账号登录微信小程序后，在运营工作区选择“资金记录”。入口需要已有经营数据权限；仅能审核或考核的账号不会获得该权限。

1. 选择北京时间日期，再选择“测试资金记录”或“正式微信渠道记录”。
2. 点击“查询所选资金记录”。查看本地成功支付、退款与净额，以及异常、未成功记录数量。
3. 修改日期或渠道后旧结果会清除，重新查询得到对应结果。离开页面或切换身份也会清除。
4. 显示“未知”时不能把它当零；应由管理员核对原记录和异常来源。未来日期不可查询，超过单日记录上限需联系管理员核对。

支付和退款各按成功日期统计，所以当天退款可能来自前一天支付，本地净额可以为负。测试资金不代表真实扣款；正式渠道记录仍只是系统内记录。

渠道账单尚未接入，渠道净额和对账差额始终未知。此页不会执行支付、退款或结算。
