# How to 使用小程序受限运营入口

适用2026-10-29微信小程序源码版本。初始页选择“运营审核 · 独立账号登录”，使用运营账号及对应验证。运营使用独立内存会话，不能复用车主、商家或技师令牌。权限按职责授予；PC运营后台不在本期交付范围。正式短信未开通时，自动测试只在隔离库使用标识清楚的合成会话，不代表管理员可在普通包绕过登录。

1. 登录后核对“我的权限”。运营工作区按账号权限显示分组入口，部分专职账号会进入相应工作页；未出现入口时联系管理员核对授权，不通过构造链接获取权限。
2. 审核商家入驻、目录或公开内容前先核对来源及版本。审核经验需车主已明确授权，缺有效车型或来源时不能批准；驳回先选理由。不能代车主同意公开或修改原文。
3. 按职责进入规则、券池、积分、邀请、诊断、考核或价格来源页面。规则修改和月结是业务写操作，先核对对象和生效范围，保存后重新读取版本/审计；不能以测试政策代替正式运营政策。
4. 经营数据权限允许进入“资金记录”，选择北京时间日期和单个渠道再查询。测试资金与正式记录分别显示，切换条件会清旧结果；未知不是零，渠道账单与差额仍未知。[资金操作](LOCAL_FINANCE.md)。
5. 使用页面退出功能撤销会话；退出失败按提示重试服务端撤销，不把关闭页面等同已退出。

## 管理配置与验收交接

管理员按[网络环境说明](../operations/MINIAPP_NETWORK_ENVIRONMENTS.md)配置直连或云托管；客户端只能放公开连接信息，不能放AppSecret、JWT密钥或存储密钥。云托管需环境ID和服务名同时配置，后端身份信任启用前需完成入口隔离。

开关启用前核对对应迁移、运营政策和正式身份条件，不能直接将所有_ENABLED设为true。[模板变量索引](../delivery/MINIAPP_REFERENCE.md)只列三份受版本控制的模板，不反映生产实际值。上传需存储与扫描均可用；接入正式支付、OCR/ASR或消息渠道需要适配和验收，填写环境变量不能代替功能开发。

## 验证与排错

写操作后重新读取确认，权限变化后旧聚合应清除。401重新登录，403核对权限，资源不存在核对归属；503可能是关闭开关或未配置上游，交管理员定位。异常金额由管理员核对原支付/退款事实；本页不补写账单或直接发起资金操作。

[运营账号运维](../operations/OPERATOR_ACCOUNTS.md) · [交付剩余验收](../delivery/REMAINING_ACCEPTANCE.md)。

VIN来源管理：后端默认关闭；开启前检查NHTSA数据用途、地区覆盖和出口，必须显式VIN_DECODER_PROVIDER=NHTSA_VPIC。NHTSA候选不会自动进入车型目录，国内车型映射另按授权资料审核。关闭/失败保持手动录车；[配置与验收](../api/VIN_OWNER_GATEWAY.md)。

行驶证识别配置与验收：LICENSE_OCR默认关闭，先核对私有上传/扫描、受限worker和后端URL/token匹配；仅车主新车用途可用，管理员不能凭file_id读其他车主照片。关闭后保留手动录车。正式使用前明确图片保留/本人删除政策，准备授权证件对照与真机样本，分别记录替身/合成图/真实效果。[配置与接入步骤](../api/LICENSE_RECOGNITION.md)。

## ASR转写边界（R3）

ASR默认关闭，先执行V063及前置迁移，核对私有服务/同用途材料权限、离线模型和完整依赖锁。任务lease失效标WORKER_LOST而非自动重推，候选TTL清理不代表原音频删除。运营角色不能读取任意车主转写或借管理权限跨用途处理。 [操作、状态与接入](../api/ASR_JOBS.md)。授权真实声音的领域效果与手机仍待验，固定模型历史合成样本不等同真实用户效果。

## 图文服务运维交接（R4b）

业务管理员没有通过页面启用模型或查看任意车主文档的权限。服务负责人按[配置与受限测试覆盖](../../services/documents/README.md)准备资源、执行V064、核对独立开关及私有网络/token；只监控安全状态/限额/故障码，不收集材料正文或token。启用前按[测试报告](../progress/RECOGNITION_R4B_DOCUMENT_JOBS.md)区分合成业务、真实模型和真实用户证据。关闭后候选不会恢复；TTL与取消不删除原文件。

## 嵌入索引授权（R5a）

资料管理新增“单独允许本地私有嵌入索引”，默认未选，不由检索/摘录/AI用途自动推导。新建、编辑草稿、保存后或换身份都须重新核对；确认预览包含许可及策略。旧资料没有该字段即未授权，原哈希保持不变。该许可不授权外部第三方模型，也不代表索引已经生成。当前默认KEYWORD；自动索引/状态及公开VECTOR须由负责人按后文R5c1/R5c2独立配置，见[接口与边界](../api/KNOWLEDGE_VECTOR_FOUNDATION.md)。

## 自动索引与状态查看（R5c1）

配置负责人显式启用后，已发布且独立授权的当前有效资料会由后台有限扫描生成索引。资料列表点“刷新并核对资料”可看等待发现、排队、生成、完成、失败、取消或关闭状态。页面不提供模型启用或无限重试按钮；失败任务先按安全错误码核查，不能把刷新等同重试。旧回执和许可预览不变，状态不证明资料真实或汽车领域效果。跨配置清理须停止所有索引实例后使用独立维护模式，见[配置、清理与故障手册](../operations/KNOWLEDGE_EMBEDDING_LIFECYCLE.md)。车主公开检索默认KEYWORD，VECTOR另按下文R5c2显式配置。

## 公开向量查询接入（R5c2）

服务负责人明确启用KNOWLEDGE_VECTOR_ENABLED，须已配置知识库和自动索引，默认关闭。运营仍需逐项确认独立嵌入与AI许可，缺任何当前资料的有效索引会显示关键词降级；不要通过修改数据库任务状态伪造就绪。公开查询独立12秒预算，无无限重试；停止资料立即停止后续引用，AI调用后会再核验。新界面显示本次方法和实际片段，不承诺领域准确率。[规则、配置及验收](../api/KNOWLEDGE_VECTOR_RETRIEVAL.md)。

## 索引失败处理（2026-10-29）

页面显示“生成失败”时先记录任务和固定错误码。刷新不会触发重试。服务负责人可按[维护指南](../operations/KNOWLEDGE_EMBEDDING_LIFECYCLE.md)显式启用有限瞬时重试，默认每任务最多2次，配额和审计在重启后保留；永久错误、过期/撤回/取消资料不会借重试恢复。达到配额后先修复根因，按正式编辑/发布流程建立新版本，不手工改状态或删除审计。运营权限仍不能查看车主私有原文、向量或服务凭据。

## 2026-10-30 新增配置交接

本地车型规则由服务端负责人按[VIN授权规则手册](../operations/VIN_LOCAL_SOURCE.md)配置并校验文件SHA、有效期、数据授权和精确目录关系。运营维护的品牌/车系/年款/配置名称必须与授权映射一致，停用立即影响候选确认和最终保存。不得将合成夹具改标为真实数据。

汽车生活合作服务默认关闭。按[接入手册](../operations/CAR_LIFE_SERVICES.md)核验合同、固定HTTPS页面和微信业务域名；配置后重新构建，真机验收加载/取消/退出/异常。没有真实合作服务验收时保持未开通。
