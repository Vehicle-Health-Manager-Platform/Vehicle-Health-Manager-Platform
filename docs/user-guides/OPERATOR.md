# How to 使用小程序受限运营入口

适用2026-10-23当前微信小程序源码版本。初始页选择“运营审核 · 独立账号登录”，使用运营账号及对应验证。运营使用独立内存会话，不能复用车主、商家或技师令牌。权限按职责授予；PC运营后台不在本期交付范围。

1. 登录后核对“我的权限”。运营工作区按账号权限显示分组入口，部分专职账号会进入相应工作页；未出现入口时联系管理员核对授权，不通过构造链接获取权限。
2. 审核商家入驻、目录或公开内容前先核对来源及版本。审核经验需车主已明确授权，缺有效车型或来源时不能批准；驳回先选理由。不能代车主同意公开或修改原文。
3. 按职责进入规则、券池、积分、邀请、诊断、考核或价格来源页面。规则修改和月结是业务写操作，先核对对象和生效范围，保存后重新读取版本/审计；不能以测试政策代替正式运营政策。
4. 经营数据权限允许进入“资金记录”，选择北京时间日期和单个渠道再查询。测试资金与正式记录分别显示，切换条件会清旧结果；未知不是零，渠道账单与差额仍未知。[资金操作](LOCAL_FINANCE.md)。
5. 使用页面退出功能撤销会话；退出失败按提示重试服务端撤销，不把关闭页面等同已退出。

## 管理配置与验收交接

管理员按[网络环境说明](../operations/MINIAPP_NETWORK_ENVIRONMENTS.md)配置直连或云托管；客户端只能放公开连接信息，不能放AppSecret、JWT密钥或存储密钥。云托管需环境ID和服务名同时配置，后端身份信任启用前需完成入口隔离。

开关启用前核对对应迁移、运营政策和正式身份条件，不能直接将所有_ENABLED设为true。[模板变量索引](../delivery/MINIAPP_REFERENCE.md)只列三份受版本控制的模板，不反映生产实际值。上传需存储与扫描均可用；接入正式支付、OCR/ASR或消息渠道需要适配和验收，填写环境变量不能代替功能开发。

## 验证与排错

写操作后重新读取确认，权限变化后旧聚合应清除。401重新登录，403核对权限，资源不存在核对归属；503可能是关闭开关或未配置上游，交管理员定位。异常金额由管理员核对原支付/退款事实；本页不补写账单或直接发起资金操作。

[运营账号运维](../operations/OPERATOR_ACCOUNTS.md) · [交付剩余验收](../delivery/REMAINING_ACCEPTANCE.md)。

VIN来源管理：后端默认关闭；开启前检查NHTSA数据用途、地区覆盖和出口，必须显式VIN_DECODER_PROVIDER=NHTSA_VPIC。NHTSA候选不会自动进入车型目录，国内车型映射另按授权资料审核。关闭/失败保持手动录车；[配置与验收](../api/VIN_OWNER_GATEWAY.md)。

行驶证识别配置与验收：LICENSE_OCR默认关闭，先核对私有上传/扫描、受限worker和后端URL/token匹配；仅车主新车用途可用，管理员不能凭file_id读其他车主照片。关闭后保留手动录车。正式使用前明确图片保留/本人删除政策，准备授权证件对照与真机样本，分别记录替身/合成图/真实效果。[配置与接入步骤](../api/LICENSE_RECOGNITION.md)。
