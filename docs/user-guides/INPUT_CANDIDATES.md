# 从材料整理并核对内容

车辆登记、档案录入、行驶证资料和AI问题页新增“材料内容核对”。可对照证件、照片、PDF或本人录音手动摘录。档案新增页另提供可选的里程图片识别入口，后端默认关闭，需要部署配置后才能返回候选。

1. 点击“手动整理候选”，仅填写要带入的项目。空项保留原表单值。
2. 点击“检查候选内容”，逐项对照原材料；VIN、车牌、里程和日期不符合格式时先修改。
3. 勾选“我已逐项对照原材料核对”，点击“确认带入表单”。此时尚未保存或发送。
4. 再检查原表单，然后点击原“保存车辆”“保存档案”“保存本人资料”或AI“发送”。行驶证来源核对仍需按原页面要求完成。

修改候选后需重新检查。原表单在整理期间变化时，请取消重新整理；切号、换车、切换档案、离开页面会丢弃未确认候选。取消只清除候选，不删除原材料；已带入内容按原表单规则管理。

车辆里程候选用于新车登记，档案中的里程是该条历史记录，不自动更新登记里程。VIN不会自动解码车型；文字AI不会自动接收材料。真实转写、真实OCR模型和手机识别旅程仍待验，不以本机候选流程作为识别效果验收。

## 档案图片里程识别（可选）

先上传图片，在“材料内容核对”中明确选择其中一张，勾选“同意将选定图片用于本次里程识别”，再点击识别。只发送选定图片和车辆标识，图片由服务端读取；不会自动识别其他图片。

返回的里程仍须对照图片、检查候选、勾选本人核对并确认带入；低可信度也走相同步骤。无法确定多个里程时不自动挑选，服务未启用、失败或超时可继续手动整理。确认带入后尚未保存，最后检查原表单再点击“保存档案”。

识别期间可以取消；更换选图、撤回同意、切换车辆/账号/类型、图片集合变化或离开页面会清除本次未确认候选并撤销同意。上述取消后重新识别需重新同意。它仅填写本条档案的里程，不更新车辆登记里程。
