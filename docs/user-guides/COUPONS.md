# 券发行、领取和有效期

## 门店店长

门店登录→管理本店券库存与发行→创建草稿。选择本店在售项目，填写类型、优惠/门槛、库存及北京时间有效期。兑换券金额/门槛为零；金额券填写两位小数。草稿可修改，发布即冻结条款，条件改变请新建券。停止新领取不撤回已领权益。

店员无权管理。无在售项目先维护服务；权限/版本/项目/库存变化时重新读取。网络失败点击“重试原操作”，保留原编号，不另建同内容券猜测结果。

## 运营

运营入口→管理运营精选券池，需管理员独立授予权限并重新登录。已发布券可选入/移出精选曝光，优惠仍由发行门店承担。目录/审核权限不等于券池权限。

## 车主

个人中心→领取运营精选券，或门店详情→查看本店可领券。核对门店、项目和有效期后领取，每模板每人限领一次。已领、售罄、未生效、到期、来源失效券不在可领列表。

个人中心→我的券与截止日期，显示本人券及北京时间有效期。首页显示最近领取券的实际截止日期，查看全部券可翻页。旧券来源未知时请联系发行门店核对。

当前完成发行与领取，订单抵扣和服务核销将在R5b接入，此时没有用券/核销按钮。
