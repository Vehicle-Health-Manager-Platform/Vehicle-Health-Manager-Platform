# 券发行、领取和有效期

## 门店店长

门店登录→管理本店券库存与发行→创建草稿。选择本店在售项目，填写类型、优惠/门槛、库存及北京时间有效期。兑换券金额/门槛为零；金额券填写两位小数。草稿可修改，发布即冻结条款，条件改变请新建券。停止新领取不撤回已领权益。

店员无权管理。无在售项目先维护服务；权限/版本/项目/库存变化时重新读取。网络失败点击“重试原操作”，保留原编号，不另建同内容券猜测结果。

## 运营

运营入口→管理运营精选券池，需管理员独立授予权限并重新登录。已发布券可选入/移出精选曝光，优惠仍由发行门店承担。目录/审核权限不等于券池权限。

## 车主

个人中心→领取运营精选券，或门店详情→查看本店可领券。核对门店、项目和有效期后领取，每模板每人限领一次。已领、售罄、未生效、到期、来源失效券不在可领列表。

个人中心→我的券与截止日期，显示本人券及北京时间有效期。首页显示最近领取券的实际截止日期，查看全部券可翻页。旧券来源未知时请联系发行门店核对。

## 金额券预约与返还

普通预约或AI方案预约→使用金额券预约，重新选择/核对本人车、当前报价与时段。读取本人券，选择可用金额券，确认原价、优惠和现金实付后创建。每单一券、不叠加，仅发行门店指定项目；实付至少0.01元。旧来源未知、已使用/冻结、到期、不满足范围或门槛的券不能选择。

订单详情显示券冻结/消费/释放/返还状态。待付截止受券截止限制，未付取消/到期释放；支付迟到不抵扣另单券。全额退款须双方同意并确认退款成功后才返原券，不续期，可能已过期。

结果不确定时用“重试原用券预约”获取原回执，不更换选券或请求编号；离开后先核对我的订单。长期相同创建编号仍关联原订单；新预约请明确创建新请求。创建回执是当时结果，订单详情才是当前状态。

## 服务券独立核销

我的券→服务券授权/核销记录→生成授权码。请确认服务完成后向发行门店出示，授权最多10分钟且不超过券截止；重新生成使旧码失效，隐藏页面清除显示的码。

商户工作入口→服务券独立核销与记录，扫码或手填本人券编号、授权版本及32位码，先预览核对项目/本店，再确认服务交付并核销。错码受限流，按提示等待。网络结果不确定时重试原核销请求，不能重复产生消费。可查看本店唯一核销凭据。

服务券核销佣金0.00，不创建现金付款/退款，不表示微信或现金收款；现金金额券订单则按现金实付及原入驻免佣政策计佣。正式身份和资金/真机发布验收仍在最后R9。
