# 上传录音与PDF

1. 登录车主账号，选择自己的车辆，打开AI对话或档案录入。
2. 录制语音或选择PDF，先试听/预览确认。材料最多3份。
3. 点击该份材料的“上传本份材料”。只有看到“已上传 · 扫描通过 · 尚未识别”才表示本次收到成功收据。
4. 继续手动输入文字；文字提问和档案保存不会自动附带这些材料。上传不表示已经转写，也不表示同意第三方识别。

音频1–60秒、最多3MiB；PDF最多10MiB/50页。加密、表单、注释、附件、脚本等PDF不支持，请导出静态文档再选择。真实录音及文件选择效果仍需微信真机验证。

网络失败可点击原材料重试，同一次保留的材料复用原请求键。切换账号/车辆、离开页面会清除当前引用并中止等待；服务器可能已经收到请求，不能把本机取消当作服务器删除。移除按钮仅清除本机引用。

未配置直达后端地址、服务开关、身份、私有存储或扫描时，上传会提示未就绪；本机采集/查看与手动填写仍可使用。只读演示不会伪造上传成功。微信云托管JSON传输不能直接承载此multipart，需后续配置可直达HTTPS上传入口。
