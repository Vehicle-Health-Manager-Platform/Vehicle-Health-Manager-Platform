# How to 使用车主端管理车辆并完成一次服务

适用2026-10-23当前微信小程序源码版本。先在初始页选择“车主端”，完成微信登录与手机号绑定，再进入车主功能页。正式登录、真实支付及手机操作仍需验收；开发预览不提供正式业务可用性保证。

## 车辆与档案

1. 从车主入口进入底部“首页”，选择或添加本人车辆；录车入口为 `pages/vehicle/entry`。手动选择车型后核对并保存，切换车辆后再操作档案或预约。
2. 选择“档案”，录入日期、里程和实际维修/保养事实。图片、录音或PDF材料需本人核对；上传成功不等于自动识别完成。参考[材料上传](CONTROLLED_INPUT_MATERIALS.md)和[候选确认](INPUT_CANDIDATES.md)。
3. 在当前读数、历史修正及提醒页核对来源。没有有效来源时显示未知；本人目标不代表厂家标准。[健康和档案](R4_HEALTH_AND_ARCHIVES.md)。

## 预约、接车与取车

1. 在“服务”选择项目、门店及可用时段，核对车辆、价格和券后提交预约；从“我的订单”进入 `pages/order/detail`。
2. 待支付页当前明确提示正式微信支付尚未配置。不要将隔离测试付款或测试核销当作实际收款。未支付到期关闭；状态不确定时刷新或使用“核对支付结果”，不要重复下单。
3. 已支付订单向门店提供预约码；接车后查看本人接车单，核对照片、里程与损伤，再确认或填写原因提出异议。异议期间施工暂停，商家处理后由本人复核是否接受。
4. 在详情查看施工进度；仅在需要时逐条授权历史档案，可撤销。取车前进入“取车对比（接车与完工证据）”。缺证据时显示缺失，不能当作已检查无问题。
5. 待核销时向商家提供六位核销码；完成后核对核销记录、查看车辆档案，按本人实际体验提交评价。公开星级、文字、图片或经验均有各自授权和审核，私有保存不等于已公开。

退款从本人订单“取消与退款”进入，以页面实际状态及双方同意条件为准。正式退款尚未接入，申请提交不等于资金已到账。

## 其他日常任务

- AI文字交流和项目建议需已配置服务及明确用途授权；语音转写、图片/PDF理解和正式知识效果待验。失败时可改手动输入，不把无来源回答当作维修结论。
- 券与服务券按[券说明](COUPONS.md)使用；服务券核销与金额券预约是两条流程。
- 邀请资格、月度进度按[邀请说明](INVITATIONS.md)核对；积分及兑换在“我的积分”“积分兑换券”查看真实流水。
- 私有问答、人工诊断是非实时服务；站内消息不保证微信订阅消息送达。经验/问答公开前核对授权对象和范围。

## 验证与排错

保存后重新读取本人记录确认；不要仅凭成功提示判断支付、退款或公开完成。登录失效重新登录；归属不符返回本人车辆或订单；版本冲突刷新后重核。网络失败时优先使用页面标明的“原请求重试”，不要同时另发同类写操作。上传失败先检查权限和扫描状态，缺少能力时联系管理员核对配置。

[所有页面与配置索引](../delivery/MINIAPP_REFERENCE.md) · [仍需验收的事项](../delivery/REMAINING_ACCEPTANCE.md)。

档案新增页可在图片上传后，选择一张图片并同意本次里程识别用途，再请求里程候选。后端默认关闭，未配置时可手动整理；返回结果经本人核对、确认带入后，仍须单独保存档案。真实仪表效果与真机旅程尚未验收，见[候选确认](INPUT_CANDIDATES.md)。

VIN录车：添加车辆→VIN录车，输入17位VIN及可选年款。阅读NHTSA外发用途和美国市场覆盖限制，按需同意查询；候选出现后核对并勾选，再带入手动表单，仍须人工选择品牌/车系/年款/配置和里程后保存。查不到或未配置可直接手动录车，无须同意外发。隐藏页面/更换输入会清空候选；详见[VIN说明](../api/VIN_OWNER_GATEWAY.md)。

行驶证录车：添加车辆→行驶证录车→选择4MiB以内JPEG/PNG（此时仅本机）→阅读私有上传/新车识别及附件保留说明→同意后上传识别。逐项核对所有车牌/VIN候选，低可信或多值可手动修正；修正不代表模型原始结果。勾选核对后带入手动表单，再选择车型/里程并保存。照片不自动关联档案；取消不承诺删除已上传图片，不愿上传/未配置时可直接手填。[说明](../api/LICENSE_RECOGNITION.md)。
