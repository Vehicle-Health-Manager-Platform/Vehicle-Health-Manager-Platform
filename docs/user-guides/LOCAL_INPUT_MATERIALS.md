# 录音与本机辅助材料

AI对话页和“新增车辆档案”表单中有“本机辅助材料”区域。

1. 点“录制语音”，按微信提示允许使用麦克风；录制1–60秒后点“停止录音”。可以试听、停止试听或移除，取消本段不会加入材料。
2. 点“选择图片”或“选择PDF”，选择后可在本机预览。最多3份材料；图片/PDF每份最多10MiB，语音最多3MiB。
3. 当前材料尚未上传或识别，请参照材料手动填写文字。AI有材料时显示“仅发送文字”，只发送输入框中的文字；档案保存也不会上传这些辅助材料。
4. 需要把图片随档案保存时，请使用表单原有的“归档图片”上传入口，并确认上传成功后再保存。
5. 页面隐藏时停止录音和试听；离开、切号、换车或换档案类型会清除材料引用。图片/PDF系统选择器暂时遮挡页面时，同一账号与车辆下的合法返回可以保留。相册原件和微信临时文件不会由本功能删除。

权限拒绝可点“去开启权限”；当前环境不支持时继续手动填写。开发者工具界面与替身测试不代表真机麦克风、播放和PDF选择器已经验收。
