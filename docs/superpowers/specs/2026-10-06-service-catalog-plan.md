# 标准服务项目实施计划

规格已于 2026-10-06 获用户确认。使用现有本机 Docker 与隔离数据库；公网和真机在功能开发后安排。

1. 后端新增服务项目查询模块，复用 OWNER 身份校验和数据库连接；一致读取事务生成分类分页列表与计数，详情只返回启用且未删除的项目，金额用两位小数字符串。
2. 补充 HTTP 权限/参数/故障测试与真实 MySQL 集成测试，覆盖停用、删除、分页、会话撤销与金额精度。
3. 小程序新增请求适配及列表/详情状态管理；服务 Tab 接分类、分页、空态、重试与详情路由，隔离旧身份及迟到请求。
4. 测试分类竞态、分页失败恢复、隐藏页与身份切换；构建微信/H5。
5. 在固定隔离测试项目准备可重复且拒绝 ID 冲突的合成项目，重建本机后端；用真实 OWNER 会话验证接口与 H5 实际页面。只共享状态和合成项目证据，不输出凭据。
6. 更新 OpenAPI 生成源、接口说明、README 与进度；复核差异，提交并推送独立 PR，完整 CI 通过后按既有授权合并。

验收：上述本机开发与回归通过，待验收的生产价格、运营维护、商家报价、预约、公网与真机独立记录。保留用户新增的根目录开发者工具配置，不提交它们。
