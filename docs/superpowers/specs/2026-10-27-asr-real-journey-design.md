# R3c Java真实ASR任务联调与进程故障

承接PR246，用户要求规划后直接实施。选择复用现有Java任务与固定Linux模型，补真实跨进程边界；直接扩展图文会延后这些公共运行约束，仅再跑Python协议不足以证明Java调用。保持生产默认关闭、不合并、不部署。

Java沿现有Spring HTTP/JWT/MySQL旅程，新增显式开关才执行的真实ASR测试。实际音频来自固定英文合成WAV，以现有MP3规范编码。身份、CLEAN材料元数据和私有存储为明确测试夹具；真实Java HTTP客户端、调度worker、持久任务、Linux受限模型与原档案保存接口参与运行，不声称上传/扫描或微信真机已验。

ASR只接本轮标记的内部Docker网络、不发布端口，内核worker socket禁止仍执行。Docker内部网络无法直接产生宿主端口映射，独立低权限Nginx测试转发器接内部和专用桥接网络，仅绑定127.0.0.1随机端口供宿主JVM访问；只转发固定模型IP的health/transcribe，不放宽产品URL白名单。模型、源码和音频只读，2GiB/CPU2/PID128/非root等限制沿R3b。凭据只放忽略缓存私有配置，Maven日志不打印原文/token。测试创建/幂等/查询/权限、后台完成、候选不自动写业务、原档案显式幂等保存、在途取消及原会话撤销后迟到结果不交付。

故障检查分开记录：对精确核验PID/启动时间/命令的本轮实际模型子进程SIGKILL，确认安全失败和下一次恢复；通过本轮supervisor子进程实际验证父进程退出后内核杀死worker并由subreaper回收；独立低内存容器运行真实模型，依据cgroup OOM事件判断资源耗尽，不把普通退出当OOM。所有故障只针对本轮创建并验证归属的进程/容器，清理失败必须报失败。

退出标准：可复现显式入口、真实同版联调和故障证据、已发现问题修复回归、交接说明与草稿PR。中文/方言/噪声/真实用户准确率、手机、云上传和生产性能仍另验；原表单API保存不等于本轮渲染交互验收。若环境故障阻碍某项，记录原因并完成其他独立工作。
