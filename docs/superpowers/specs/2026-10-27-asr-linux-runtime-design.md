# R3b ASR Linux实际运行设计

用户已要求规划后直接实施，承接PR245，不合并或发布。现阶段已有默认关闭的ASR软件任务闭环，但完整依赖、权重、Linux实际推理尚未验证。

选择先验证已有ASR运行环境，再接R4图文和R5向量。直接扩展图文会延后公共隔离问题；只编写资源说明则不能证实真实加载。本轮取得公开MIT模型的固定revision资源，在独立Linux/Python3.11环境生成完整wheel/hash锁，安装时禁止联网。模型与大文件只保留忽略的.cache，不进入Git。

资源记录包括模型来源/revision/文件摘要、平台、实际包版本及wheel摘要。不得用随机revision、manifest生成成功或合成文本替代实际推理。默认开关保持关闭；许可依据记录公开模型MIT声明，不代表获授权真实语音数据或业务准确率验收。

构建现有Dockerfile，容器限制内存2GiB以内、CPU2、PID、只读rootfs、只读模型、非root、cap-drop及no-new-privileges，无公网端口；离线测试可用network=none，内部HTTP测试只在容器回环。受限子进程必须实际禁止socket，验证真实推理、坏数据、凭据、并发、超时、退出和清理。只注入本轮创建并核对身份的容器/进程，清理仅操作本轮资源。

测试音频为有明确来源的合成语音/静音，音频规范沿现有MP3 16k mono/48kbps/1..60秒。记录识别原文和预期差异，不以单样本推断普通话、方言、噪声或真实用户效果。若下载/平台失败，保留具体失败及可复现准备工具，完成不依赖资源的工作。

退出标准：可复现资源锁与准备/验收入口，实际容器结果和独立协议回归，修复已发现问题，脱敏报告/已知限制、交接说明和草稿PR。没有完成的真实效果仍明确待验；图文和向量另阶段实现。
