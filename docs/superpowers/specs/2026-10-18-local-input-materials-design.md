# R9-A1 / A2a：录音与附件的本机采集

2026-10-18。依据用户已确认的独立功能优先队列及“规划后开始实施、每阶段上传”的指示。本设计落实 A2 的首个可独立交付单元，后续受控媒体上传作为 A2b 单列，不能提前把整 A2 标为完成。

## 选择与范围

复用现有页面，增加共享的本机辅助材料组件。其他可选方案是先改造后端媒体上传，或直接接外部识别；前者涉及格式安全和受控访问的独立契约，后者依赖供应商。采用先采集、后上传及识别的顺序，本阶段不改变现有图片文件策略、档案 input_type 或文本 AI 正文。

- 档案录入与 AI 对话均可本机录音、停止、试听、移除；可选择本机图片及 PDF。
- 单次最多3份辅助材料，每份图片/PDF最多10MiB；音频格式MP3、单声道、16000Hz、48000bps，1–60秒且最多3MiB。
- 本机文件仅用于查看和人工填写；没有识别服务时明确提示未转写、未上传，也不会随文字提问或档案保存发送。
- 既有档案“归档图片”仍走现有受控图片上传；本机辅助材料与归档图片分别呈现。
- 本阶段无需新增API或SQL。音频/PDF的服务器校验、扫描、上传、签发及用途授权留 A2b；ASR/OCR/多模态供应商与真机效果继续 B2。

## 状态与归属

状态为 idle、requesting、recording、stopping、selecting、reading、playing。忙碌时不接受重复开始/选择；同一原生录音管理器只允许一个活动采集者。录音的最终 stop/error 到来前不把单例交给其他组件，避免旧回调串入新录音。

每次异步操作捕获账号、车辆/页面范围和操作代次。切号、换车、换档案类型、卸载均作废旧操作；晚到的选图、文件大小、录音和播放回调不能恢复旧材料。录音隐藏时立即请求停止且丢弃本段，播放隐藏时停止并销毁。

系统文件/图片选择器可能触发页面隐藏：选择期间先隐藏辅助材料，在当前账号/范围未变且页面重新显示后接受合法结果；卸载或上下文改变则丢弃。档案表单在辅助选择器打开时保留本人未提交文字，其他身份变化仍清空。

辅助材料只在内存中保存引用，不写URL、日志或本机持久存储。清除引用不宣称删除相册原件或微信管理的临时文件；绝不删除用户原始文件。文本AI与档案正文不携带辅助文件路径、文件名或音频。

## 失败处理

用户取消选择不报错；不支持录音/PDF选择时给出能力提示与手动回退。权限拒绝可打开设置；超大、空文件、非法PDF名称/扩展名和录音时长不合规不加入列表。原生错误仅转换为固定中文提示，不回显原始路径或错误内容。

试听上下文仅播放已选本机音频，不接受外部URL；每次播放重新核对本次材料与身份。取消、停止或销毁后迟到的播放事件无效。
