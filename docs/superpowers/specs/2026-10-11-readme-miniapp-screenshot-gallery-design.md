# README 微信小程序演示图集设计

## 目标

在仓库根目录 README 展示真实微信开发者工具模拟器中的小程序画面，帮助读者快速了解车主、门店和运营入口。图集只展示界面，不宣称真机、生产身份或资金验收已经完成。

## 内容与来源

使用工作区已有的三张模拟器截图，并复制为仓库内可长期引用的静态素材：

| README 展示名 | 来源截图 | 展示内容 |
| --- | --- | --- |
| 车主入口 | `test-results/wechat-owner.png` | 车主小程序入口与登录提示 |
| 门店派工 | `test-results/native-dispatch-after.png` | 使用合成订单与技师数据的派工确认弹窗 |
| 运营审核入口 | `test-results/wechat-native-operator-login.png` | 小程序运营审核登录表单 |

最终素材存放于 `docs/ui/screenshots/`，使用清晰、稳定的角色名文件名。不得引用被 Git 忽略的 `test-results/` 路径，不添加黑屏加载截图，不把旧 H5 原型预览作为小程序画面。

## README 呈现

在项目简介和角色说明之后新增“微信小程序界面演示”小节，以三列图集展示截图和简短中文说明。图片替代文本描述截图内容。图集旁明确说明这些是微信开发者工具模拟器画面，门店派工数据为合成数据；它们用于展示页面形态，不代表真机或生产环境验收。

## 验收

- 三个图片资源存在于仓库内，README 使用相对路径且替代文本非空。
- README 不引用旧 H5 原型截图或忽略目录中的测试产物。
- 图片可直接打开，图像中不含真实用户身份、令牌、私有配置或真实资金数据。
- `git diff --check` 通过；检查每个 README 图片路径能解析到文件。
