问答：受理政策草稿/修改/发布/停止；两条问题分别由车主和当前处理者关闭，覆盖队列最小投影、正文权限独立、获派后读/答复、补充、重分配和旧处理者撤权。创建恢复返回原回执，不能将其误当当前状态。管理、处理、知识库、审核四类运营权限独立，跨用户不能读私有正文。不得默认公开、发积分或混入人工诊断。
