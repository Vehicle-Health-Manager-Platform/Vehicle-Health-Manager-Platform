# 三角色本地只读预览

用户要求跳过登录，查看车主、商家、技师后续内容。采用上一轮提出的隔离本地演示方案，复用现有业务页面，由独立构建注入合成会话与内存响应；正式后端鉴权保持原样。

- 输出固定为 `.cache/local-preview/mp-weixin`，构建命令 `npm run preview:miniapp`。普通构建不含预览会话、数据或请求替换。
- 三角色均使用不可作为 JWT 的演示标记，仅留在内存；页面显示本地演示说明及切换角色按钮。
- 主要车辆、档案、服务目录、订单、门店员工/报价、施工工作区和技师工单提供合成数据。未覆盖页面明确提示没有演示样本，不伪造正式结果。
- 所有请求由预览传输层处理，无真实网络回退；支付、短信、上传及其他写操作拒绝并提示只读。AI 对话若演示回复则明确标为固定示例，不连接模型。
- 预览只能在开发者工具运行；账号与数据不持久化。重新打开三角色入口可切换角色。
- 验证实际客户端契约能读取样本、写请求与未知请求均不访问网络、普通构建不含演示标记，以及模拟器中三角色主要页面确实呈现内容。

这是界面浏览辅助，不计为正式登录、真实资金、业务端到端或真机验收通过。
