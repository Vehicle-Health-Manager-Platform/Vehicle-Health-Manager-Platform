# 本机商家报价查询与选品定价

日期：2026-10-06。基线：PR #22 合并提交 `fb85693`，合并后主分支 CI 六项成功。状态：价格规则已确认，其余书面规格待复核。

## 目标与范围

继续本机功能开发。车主在标准项目详情查看商家报价；已审核商家可维护本店选品、报价和上下架。对应 F06 报价子集与 F17；预约/支付另行设计，正式短信、公网和真机后置。

可选交付路径：只做车主读取最快，但报价只能人工准备；先做商家接口可验证写入，用户页面仍断开；推荐本步同时接通车主读取与商家维护页面，独立验证完整报价链路。

## 已确认价格规则

报价允许 0.01–99999999.99 元，两位小数字符串；数据库使用 DECIMAL，服务端采用十进制定点校验与计算。拒绝数字类型、负数、零、科学计数、超过两位小数与越界金额；不以浮点计算。参考价仅供对照，`float_ratio` 不用于未明确的限价公式。

## 数据与事务

- 复用 `standard_project`、`merchant`、`merchant_project`。同店同项目唯一，不依赖客户端提供商家 ID。
- 新增 V006 报价版本表，保存报价记录 ID、单调版本号、价格、上下架状态、操作员工及时间；每次成功维护追加不可变版本，不覆盖历史。有效既有报价迁移为初始版本，迁移脚本可重复执行且不覆盖现有版本；迁移前备份已有库，新库初始化按序执行。
- 写接口复用 24 小时幂等和成功审计，报价/版本/响应/审计同事务。重放时也重新校验当前身份与项目条件；同键异文拒绝。不同员工同时维护同店同项目时用数据库锁串行提交版本，价格修改失败不产生版本或审计。
- 已有订单金额和字段不被维护接口更新；未来订单创建保存报价版本与项目/商家快照，订单模块交付时独立验收。

## 接口契约

统一 ApiResponse/no-store、金额两位小数字符串，分页默认 1/20，页大小上限 100；校验合法分页与安全整数 ID。

| 接口 | 身份与参数 | 结果 |
| --- | --- | --- |
| `GET /api/service/project/{id}/merchants` | 有效 OWNER；`sort=price_asc/price_desc` 默认升序及分页 | `items,total,page,page_size`；条目含报价 ID/版本 ID/版本号、商家 ID/名称/地址及价格 |
| `GET /api/merchant/standard-projects` | 有效 MERCHANT；可选分类、分页 | 启用且未删除的标准项目及参考价，用于选品 |
| `GET /api/merchant/projects` | 有效 MERCHANT；分页 | 本店已选项目、报价、上下架、当前版本及标准项目是否可售；包括已下架项目 |
| `POST /api/merchant/projects` | 有效 MERCHANT + Idempotency-Key；严格字段 `standard_project_id,price,status`，status 为 0/1 | 本店报价 ID、新版本 ID/版本号、价格和状态 |

车主只见已审核且未删除商家、启用未删除标准项目、在售未删除报价；排序用价格再报价 ID 保持同价稳定。项目不存在/停用/删除返回 404，可用项目无商家返回空列表。列表与计数使用同一读取事务及相同条件。接口不返回商家私人联系方式、资质或内部员工信息。

商家只可操作 JWT 关联的本店；复核员工 ACTIVE/MERCHANT、本店审核通过且未删除、会话未撤销/过期。OWNER、TECHNICIAN 和绑定凭证不得调用商家维护接口。请求出现 merchant_id 或其他额外字段直接拒绝。

标准项目不可售时，禁止新增、改价或上架；本店已有报价仍可按原价下架。对软删除的本店报价不自动恢复。无效参数 400，身份无效 401，角色不符 403，资源不可用 404，数据库/事务故障 503；错误不泄漏 SQL 或私有信息。

## 小程序

- 车主项目详情新增报价列表、价格升/降序、分页、空态与重试；状态切换隔离迟到响应。展示商家名称、地址和报价；有价格数据才展示，不生成距离、评分或评价总结。
- 商家登录成功后提供“管理本店服务”入口，保存独立商家内存会话；退出或身份变化清空列表、编辑表单及待提交状态。
- 本店服务页展示已选项目与上下架状态，提供标准项目选择、价格输入、上架/下架、保存和重试。成功更新后重新查询服务器结果。
- 网络结果不明确时，同一表单原键重试；修改表单内容换键。提交中阻止重复点击，身份变化/页面隐藏后迟到结果不得覆盖当前状态。
- 沿用当前视觉与登录错误处理；所有项目/商家文字纯文本显示。

## 本机验证及边界

真实商家短信仍未接入。后端完整集成测试用隔离的合成商家/员工和真实数据库验证会话、权限、价格、版本/审计与幂等；本机 H5 商家维护用明确标为合成的 MERCHANT 测试会话，不标记为真实短信登录。

若需浏览器测试会话，由显式授权的回环测试工具在固定隔离库创建短时会话并签发，只服务本地验收；核对项目/保留 ID 冲突，只用私有 JWT 配置，不在业务后端增加绕过登录的入口。H5 登录响应桥接明确记为测试替身，报价业务请求仍走真实接口；结束撤销测试会话，不打印/提交令牌或密钥。

覆盖两店隔离、禁用员工/商家/项目、匿名/跨角色、精确金额、价格排序/分页、上下架可见性、历史版本、并发修改、原键重试、事务失败补偿，以及小程序竞态和编辑重试。只在隔离库准备合成项目/报价，不作为生产数据。微信/H5 构建和独立 PR 完整 CI 必须通过；实际观测、替身和未执行项分别记录。
