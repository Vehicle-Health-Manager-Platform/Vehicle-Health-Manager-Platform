# 社区图片真实验收设计

用户已授权规划并实施，沿用每阶段上传GitHub的要求。复用现有生产接口，不改生产发布开关。

采用真实 HTTP + MySQL + 私有 MinIO + ClamAV 引擎，覆盖11接口的正常、边界、错误和越权。相较仅元数据夹具，这条链验证实际PNG字节与原图隔离；无需接入真实用户和支付供应商。

原图与独立副本分别上传，经父经验同意审核、图片预览与哈希绑定后提交。审核失败必须回滚；通过后只返回重编码PNG。验证拒绝、撤回、重复回执、再次提交新UUID、父经验撤回隐藏和本人历史预览。

证据绑定真实响应的经验UUID、档案ID、预览哈希及两个公开UUID，逐条比较请求路径和正文，拒绝缺失或篡改。JUnit成功、源码一致、12项不变量及五类测试资源实际移除后才计入所选历史证据。

合成前序订单/支付/报告不代表真实支付验收；合成病毒库不代表生产病毒覆盖；元数据清除不代表自动遮挡车牌或人脸。
