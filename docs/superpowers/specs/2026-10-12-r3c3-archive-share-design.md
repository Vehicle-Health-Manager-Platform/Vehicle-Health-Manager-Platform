# R3c3 档案摘要限时分享与撤销

## 已确认范围

2026-10-12，用户确认：接收者登录车主小程序后持链接即可只读查看；有效期为 1 小时、24 小时（默认）、7 天；车主可撤销。链接可以转发给其他已登录车主。不要求逐人批准。

## 数据与权限

创建时固定摘要快照，避免后续录入的档案被旧链接自动分享。仅包含生成时间、日期范围、无日期记录计数、登记里程，以及记录的类别、来源类型、日期、里程、报工分钟和测试标记。最多 500 条。车型名称、车牌、VIN、备注、标题、配件名称、图片、签字、PDF 和内部业务 ID 均不进入摘要。

创建、列表、取链接、撤销仅限车辆当前车主，均检查有效会话、账号与车辆归属。读取摘要需有效车主会话，并检查分享未过期、未撤销、原车主账号正常且车辆仍归原车主。撤销与读取锁定同一分享记录；撤销提交后的新读取返回 410。已读取的内容无法从接收者记忆或截图中收回。

数据库只保存能力令牌的 SHA-256 摘要；随机 UUID 与服务端 JWT_SECRET 经独立 HMAC 域生成令牌。创建幂等回执不含令牌，车主通过单独的只读接口取得链接。轮换 JWT_SECRET 后旧链接失效。令牌仅放小程序分享路由及接收请求正文，不放 API URL、日志、审计或本地存储。摘要访问成功写入最小审计，所有响应 no-store。

## 微信小程序流程

档案页进入分享管理：选择日期范围与有效期、创建、准备分享、原生转发、查看状态、撤销。接收页展示脱敏固定字段与只读提示；未登录时进入车主登录，再返回继续查看。页面隐藏即清空已展示摘要，重新进入重新校验。异常状态区分登录失效、链接失效、服务不可用，提供重试。

## 验收

覆盖字段白名单、幂等、越权、会话失效、过期/撤销、车辆归属变化、账号停用、审计失败回滚、重试及小程序路由构建。真实微信登录及真机转发列为待验收，不以 H5 构建代替。
