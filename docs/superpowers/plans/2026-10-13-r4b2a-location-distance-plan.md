# R4b2a 实施计划

2026-10-13。规格见 [位置与距离](../specs/2026-10-13-r4b2a-location-distance-design.md)，下一业务为 R4b2b 公开评价。

1. 规格：固定手工确认 GCJ02 来源、旧坐标隔离、只读 POST 隐私边界、未知距离/排序和生命周期；自审契约并提交规格与计划。
2. 后端：V032 位置表及迁移重放；店长维护/清除及本店读取；严格输入与共享距离 SQL；车主附近报价、详情距离；权限、事务和幂等测试。同步 API/OpenAPI、SQL 字典及 schema 校验。
3. 微信：位置维护页及门店资料入口；主动定位适配、附近/价格/区域分页；详情单独请求定位；隐藏/账号切换销毁坐标及迟到请求保护；注册定位权限与页面，测试并构建。
4. 收口：定向真实数据库/HTTP 测试、小程序全量及微信/H5构建；检查生成文件、差异、需求追踪、未验收事实；写执行和验收记录、更新当前/下一步；推送本阶段 PR（依赖 #141，不自动合并），检查六项 CI 并修复失败。

每一步写明实际结果；文档和代码在同一 R4b2a 分支以提交保留，完整阶段上传 GitHub PR。外部识别、正式短信/身份/资金与真机发布保持 R9；本阶段不以替身结果充作真机证据。
