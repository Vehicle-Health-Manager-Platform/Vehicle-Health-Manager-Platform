## 关于动画（GIF）

根 README 目前**没有**内嵌截图，也没有内嵌 GIF，原因如实记录如下：

- GitHub 的 Markdown 渲染只支持静态图片与静态 Mermaid SVG，不执行 JavaScript；Mermaid 图不会播放动画。
- 若要展示"会动的流程"，只能提交一个 **GIF 文件**（GitHub 会像普通图片一样循环播放）。
- 本仓库当前的开发环境中**未安装微信开发者工具**，无法从真实运行的小程序里录屏转 GIF；用生成的图片或拼接的静态图冒充运行录屏会失真，因此不做。

补一张真实 GIF 的步骤（有开发者工具的环境下）：

1. `npm run build:miniapp`，用开发者工具导入 `apps/miniapp/dist/build/mp-weixin`；
2. 用演示数据（合成订单/合成技师）走一遍要展示的流程，`Win + G`（Windows）或系统录屏录制模拟器窗口；
3. 裁掉状态栏与无关区域，转成 **宽度 ≤ 800px、时长 ≤ 10s、体积 ≤ 5MB** 的 GIF（循环播放）；
4. 存为 `docs/ui/screenshots/<流程名>.gif`，在本文件登记来源与录制日期；
5. 需要展示时用 `![替代文本](docs/ui/screenshots/<流程名>.gif)` 引用（根 README 的界面预览章节已移除，可在用户手册或其他说明页引用），并保留静态 Mermaid 流程图作为补充说明。

录制前请确认画面中没有真实手机号、车牌、VIN、头像、账号或内网地址。
