# UI 规范与原型

目标 UI 以恢复的原始交付文档 §4–5 为依据：车主、商家、技师为微信小程序，运营为 PC 网页。现有 `packages/web-shell/` 和 `/ui` 是此前四端网页方案的过渡原型，可参考色值、状态与信息层级；它们尚未实现小程序原生导航、rpx、安全区、授权流程或真机交互，不能计作目标终端验收。

## 视觉与结构

小程序设计以 375×667、最大 750rpx 为基准，运营端以 PC 布局为基准；车主 H5 另做兜底适配。既有网页公共壳使用健康绿 `#00B42A`、浅灰页面 `#F2F3F5` 和白色工作区；状态提示沿用交付文档的紧急红、警告橙、正常绿、信息蓝、待办橘。横向“车况提示”色带只用于预览五级状态，不代表真实健康评分。

页面字体优先系统中文无衬线；车辆里程、VIN、车牌等数据将使用等宽数字样式。桌面左侧导航宽 220px，移动端改为可横向滚动的页面导航。基础间距按 4/8/12/16/20/24/32/40/48px，按钮与输入框最低 44px。键盘焦点需明显可见，骨架动画遵循系统减少动态效果设置。

## 公共组件

| 组件 | 已提供状态 | 后续接入要求 |
| --- | --- | --- |
| `UiState.vue` | 加载骨架、空、错误、无权限、断网；错误和断网提供重试事件 | 页面根据实际网络/权限结果传入状态，不以本地演示状态代替真实数据 |
| `BaseField.vue` | 默认、聚焦、错误、禁用；关联标签、提示和错误文本 | 表单负责校验、提交与服务端错误映射 |

当前四端业务页面仍是网页路由占位，实际首页、订单、接车等小程序页面将在对应阶段按交付文档 §5 实现。此前四端网页 `npm run build`、HTTP 200 和 [390px 网页预览截图](s0-mobile-preview.png)只是过渡原型证据；小程序构建、微信开发者工具和真机验收仍未执行。
