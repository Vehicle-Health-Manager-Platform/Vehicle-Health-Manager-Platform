# UI 规范与原型

以交付文档 §4 的固定色值、字号、间距和组件状态，以及 §5 的页面布局为依据。S0 的共享实现位于 `packages/web-shell/`；四端运行开发服务器后打开 `/ui` 可查看状态和表单预览。`/ui` 仅在开发构建中注册。

## 视觉与结构

车主、商家、技师端优先适配手机浏览器，运营端优先适配桌面。公共壳使用健康绿 `#00B42A`、浅灰页面 `#F2F3F5` 和白色工作区；状态提示采用交付文档的紧急红、警告橙、正常绿、信息蓝、待办橘。横向“车况提示”色带只用于预览五级状态，不代表真实健康评分。

页面字体优先系统中文无衬线；车辆里程、VIN、车牌等数据将使用等宽数字样式。桌面左侧导航宽 220px，移动端改为可横向滚动的页面导航。基础间距按 4/8/12/16/20/24/32/40/48px，按钮与输入框最低 44px。键盘焦点需明显可见，骨架动画遵循系统减少动态效果设置。

## 公共组件

| 组件 | 已提供状态 | 后续接入要求 |
| --- | --- | --- |
| `UiState.vue` | 加载骨架、空、错误、无权限、断网；错误和断网提供重试事件 | 页面根据实际网络/权限结果传入状态，不以本地演示状态代替真实数据 |
| `BaseField.vue` | 默认、聚焦、错误、禁用；关联标签、提示和错误文本 | 表单负责校验、提交与服务端错误映射 |

当前四端业务页面仍是路由占位，实际首页、订单、接车等页面的具体原型将在对应阶段按照交付文档 §5 实现。S0 仅固化可复用的布局、色值和状态组件。四端 `npm run build` 已通过；gstack browse 已打开四端本地页面（HTTP 200），并在 390px 宽度查看 [移动预览截图](s0-mobile-preview.png)。
