# R8c1a 同款经验详情与引用操作

沿现有经验授权、审核和 `EXPERIENCE_PUBLICATION_ENABLED` 开关；没有新迁移或额外权限。整个 R8 完成前代码和文档留本地。

车主在“同款施工经验”选择本人车辆，点“查看当前有效详情”；或在结构化项目建议的获批同款摘要点击“重新核验经验引用”。详情只显示既有获批工时、配件种类、记录月份和获批时间，不证明本车故障或技术必做。

详情读取成功后可“复制应用内引用入口”。入口只携带随机公开编号，不含车辆、身份或登录信息。该入口用于应用内引用，不是官方微信分享、公开网页或匿名访问能力。接收者仍须登录并选择本人同款车辆；从此页前往登录后，可返回本次页面继续选择。

“重新核验此引用”读取当前来源；“刷新同款经验与引用”同时重新读取。切号、换车/车型或页面隐藏会清空详情。404 表示记录已撤回、审核/来源变化、不适合当前车型或车辆不可用，回列表重读，不把它当正常空详情；401/403 重新登录；503 核对原开关或依赖。

车主在“管理我的经验授权”撤回后，旧入口的新读取立即按当前事务拒绝。重新授权、重新审核产生新的公开编号，旧入口继续不可用；原私有档案和评价保留。车型/车系/品牌停用、原车辆转移/删除、原作者停用或施工来源/文件安全变化，也会停止后续展示。列表和详情执行同一判断，不补造审批或替换成旧来源。

当前没有热度统计、问答、图片公开或额外分享渠道。后续规则在 R8c1b/c2/c3 分步实现；正式身份/供应商/官方分享/真机及发布仍 R9。协议见[受控详情 API](../api/EXPERIENCE_DETAIL.md)。
