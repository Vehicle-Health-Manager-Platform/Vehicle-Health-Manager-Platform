# 月结页面与恢复操作（R8b2b）

2026-10-16；协议见[API](../api/MONTHLY_ASSESSMENT_VIEWS.md)。无新增迁移，沿V054/115表；全R8完成前所有源码和文档仅本地。

## 运营

有独立can_assessment的工作区或政策页进入“门店月度结算与历史”。选择有效门店、填写北京时间月份并读取；服务器给出当月当前修订、整月政策、最新结果和历史。核对月、目标、证据、等级、来源与版本后明确确认生成新修订；未结束月份禁写，无可证明政策时提示将生成未知结果。

列表和依据分别分页，不从第一页推测版本。不同只读请求期间若有新修订，页面提示刷新，不混合新旧快照。新结算仍在服务器CAS，并发一方409后重读。

遇超时、网络断开或协议异常，保留原请求并“重试原月结请求”；显示的是原门店/月/期望修订，不以当前输入代替。先读服务器核验当前权限，再原键原正文恢复。重进后即使原门店已停用，仍能通过历史和独立权限恢复已成功回执；不能对停用门店新建成绩。

本机存储失败时不会发送；服务器成功但本机清理失败仍原键清理。401保留至同账号重新认证，撤销权限后拒绝读取和回执；其他账号看不到原意图。清理损坏记录前先核对服务器，并比较记录防其他页面误删；清理不删除冻结结果，不自动重新提交。

## 店长与员工

门店工作入口“本店月度考核与本人归因”，角色由服务器本人接口确认。店长只能读本店该月所有冻结修订及最小依据，没有结算写入能力；普通员工只显示本人冻结归因的有效/剔除/未知计数，无法选择同事或读取全店成绩。没有快照时明确显示“尚无月结”，不把零候选计数当正式成绩。

未知维度不显示0分或等级；真实已核验0分仍正常显示。查看详情保留修订和采集时间，不当实时看板；后续全退在原使用月由运营显式新增修订，原施工事实仍保留，旧包不覆盖。页面不显示手机号、报工正文、私有图URL或验证码。

切号或离开页面立即清除可见数据，迟到响应无效。静态登录回跳不接受merchant_id/staff_id等查询选择器；服务端每次仍核验真实门店和角色。
