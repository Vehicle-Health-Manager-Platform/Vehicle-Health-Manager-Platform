# R8b3c2 价格比较操作

沿[来源依据配置](PRICE_MONITOR_SOURCES.md)完成 V056 和独立价格权限授予；没有新权限或迁移。全 R8 完成前全部内容保留本地。

运营工作区或“价格监控来源依据”进入“只读价格比较”，列表每页 20 条，可单独进入报价详情重新读取。核对观察时点、当前门店/项目/报价版本与服务内容，以及原发布依据的版本、单位、车型适用说明、来源和有效期。未发布草稿会明确标为草稿。

“在已确认区间内”只对当前已确认报价版本和范围有效。偏低/偏高只提示“需核对”，不能据此推定违规或执行改价/处罚/收款。页面不提供此类动作。

未知结果先按原因核对：无依据或仅草稿时完成真实来源确认/发布；未生效、到期或已停止时核对实际窗口；报价版本、项目内容/来源或门店地区变化时重新确认并新建依据，不能让旧区间自动绑定新版。仍发布的过期/失效依据占发布位，须显式停止后才能发布替代版。旧冻结快照保留供核对。

报价或发布凭证无法核验时，应核对原始操作和来源，不能补造审计或恢复旧行使其成为有效依据。软删除凭证及停止后的旧发布行回退都保持未知。页面 404 表示报价已不属于候选，应回列表刷新；401/403 重新登录并核对当前独立权限；503 保留未知状态后重读。

列表/详情均为只读，刷新会先清空旧结果，账号/权限变化或页面隐藏后不接收旧请求。c1 的原创建回执可能仍显示 comparison_available=false，该字段不代表现在的来源/窗口有效性，应进入比较页重新核验。该模块不承诺后台持续巡检。详见[API](../api/PRICE_COMPARISONS.md)。
