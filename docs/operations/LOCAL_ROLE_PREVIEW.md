# 本地三角色只读演示

2026-10-18。供开发者工具查看已有业务页面，不需要后端、数据库、微信 AppSecret 或短信。全部数据为合成样本，不代表正式业务或验收。

在仓库根目录执行 `npm run preview:miniapp`，开发者工具导入 `.cache/local-preview/mp-weixin`。这是独立工程目录，项目名为“汽车健康管家-本地只读演示”；普通构建仍在 `apps/miniapp/dist/build/mp-weixin`。

重新构建前先关闭开发者工具中的演示工程，构建成功后再打开，避免工具占用生成目录或继续运行旧缓存。验收脚本为 `node apps/miniapp/test/local-preview-smoke.cjs`，要求工具已打开该演示工程并开放本机自动化端口9420；首次编译期间脚本会等待演示启动。

入口选择车主可直接进入五个 Tab；商家与技师入口展示对应工作菜单，可以继续查看订单、派工、施工、工单等页面。页面上方和原生标题均显示演示标记，页面顶部按钮可回到三角色选择。

已有样本覆盖车辆与档案、服务目录、五种订单状态、商家报价/员工/资料/券、三端施工工作台、必要服务资料、技师待接/已接工单、施工防护与报工表单、站内消息及部分经营/积分入口。健康技术规则未配置时仍显示未知。未提供样本的页面提示“尚未配置演示样本”，不表示对应正式功能未实现。

演示使用内存会话和内存响应，不发送真实网络请求；支付、短信、上传和其他业务写入会提示只读并拒绝。AI 输入仅返回明确标注的固定示例，不调用模型，也不写积分。编辑内容不代表已经保存。

预览仅支持开发者工具，不能用来证明真实身份、资金、原生设备或生产系统已验收。普通 `npm run build:miniapp` 不含演示注入；回到普通构建后仍需配置真实后端及登录。

实现入口：`scripts/local-preview-plugin.mjs`、`scripts/build-local-preview.mjs`；样本：`apps/miniapp/preview`；契约和隔离验证：`apps/miniapp/test/local-preview.test.js`。
