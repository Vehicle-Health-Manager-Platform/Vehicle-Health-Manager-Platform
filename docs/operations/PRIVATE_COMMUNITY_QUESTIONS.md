# 私有问答操作（R8c1b2）

2026-10-17。b2a后端契约与独立权限、b2b实际车主/运营页面和本机原请求恢复已接通。整R8完成前所有代码、迁移、测试、文档留本地；不执行生产授权、发布政策或GitHub上传。

## 迁移与授权

应用V058后122表，新增community_qa_control/service_policy/case/message/case_event五表；控制行id=1只用于业务串行，不能当成受理政策。无政策、提问、消息、事件或奖励种子；两个权限默认0，原诊断和精选数据不导入。新Compose卷按V001–V058/58个SQL挂载初始化，旧卷须显式迁移，不能假定仅重启即升级。

离线operator-admin profile保持`spring.main.web-application-type=none`，指定operator.id。分配/政策管理操作`operator.action=community-manage-permission`和显式环境`OPERATOR_CAN_COMMUNITY_MANAGE=true|false`；处理操作`community-answer-permission`及`OPERATOR_CAN_COMMUNITY_ANSWER=true|false`。仅接受小写true/false，缺值和HTTP运行拒绝。授权/撤销与审计、撤销该账号旧会话同事务；需要重新登录，不能把前端旧token视为仍有权限。两个动作各自不授予另一个权限，也不继承诊断、精选或审核权限。

运营登录16字段（id、role及14权限位），本次小程序识别新形状并保留已知旧形状；两新权限在token发布前设置、切号/退出清除。仅问答管理权限登录进入私有问答受理政策，只有问答处理权限进入“分配给我”；混合权限可从运营页分别进入。管理队列不自动打开正文。

## 非实时受理和私有范围

独立管理者通过[16项API](../api/PRIVATE_COMMUNITY_QUESTIONS.md)创建有来源/有效窗口政策，读取当前有效处理人员再发布。无配置显示UNKNOWN；没有有效独立处理人员SOURCE_UNAVAILABLE；暂停或窗口外不接受新提问或补充。AVAILABLE和LEAVE_MESSAGE均非实时，没有在线或答复时限承诺。

管理队列只有case_id/版本/状态/时间/assigned_operator_id，无正文、分类、车型、车主标识；处理者只有当前获派才读正文。重分配、撤权或停用后旧处理者不可再读或回放旧回复；不凭管理权限直接关闭或读正文。车主仅主动分享所选分类、文字及车型快照，不默认共享档案或诊断资料。车辆出售/转移不转移原问答内容，原提问者可读历史，新输入仍须当前拥有原车辆。

## 失败恢复与边界

创建政策/提问保留原body及Idempotency-Key；超时或503先以同body/同key重试，不能换键重复新建。永久原创建data可在政策停止、车辆转移、通用回执过期后按当前权限取回。补充/答复/分配/关闭须保留原版本与正文，在24小时内同键恢复；过期后旧版本可能409，先读当前状态人工核对，不能解释为原写未发生。b2b页面已提供完整确认及按角色/账号/问答隔离的未决原请求恢复，非创建操作采用更保守23小时窗口；到期或记录损坏须先核对服务器再明确清理本机，不能自动换键补写。

数据库事件及审计失败会回滚正文、问答、版本和回执；没有R7通知投递、公开问答、图片共享、邀请积分任务或自动诊断。公开须b3另行授权审核，正式渠道/真机及发布仍R9。

## 页面操作

- 从“我的”或同款经验进入“我的私有车辆问答”，选择本人车辆、固定分类和主动文字，确认共享用途后预览提交。选择车辆会清除未提交文字；受理/车辆源暂不可读明确提示，不伪造空数据，历史问答仍按本人读取。
- 本人历史或运营“分配给我”进入详情，显示原提交车型和消息分页。车主补充重验当前受理及原车辆；当前获派人员回复或关闭。管理者在最小队列选择本页有效处理人员，预览目标/版本后分配，不能从该页读正文或关闭。
- 来源政策编辑以北京时间输入，保存前完整预览模式/来源/窗口；发布冻结，停止不阻断原问题的答复/关闭。来源说明仅管理可见。
- 确认后的原请求可能含私有文字，仅保存在当前设备的对应账号/业务键；不另外保存未提交草稿、token或档案。未知响应只重试原正文/原键；恢复面板展示原操作，当前表单不会替换它。退出/隐藏清内存，已有未决请求按当前身份重新核验后恢复；共享设备核对后清理本机。
