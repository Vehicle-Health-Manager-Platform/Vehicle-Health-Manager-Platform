# R8b3c1 价格来源配置操作

先迁移V056，独立can_price_monitor默认0，无区间种子、历史授予或改价。当前116表。整R8完成前代码及文档仅本地。

沿[运营离线账号管理](OPERATOR_ACCOUNTS.md)，operator-admin且web-application-type=none；受控环境显式`OPERATOR_CAN_PRICE_MONITOR=true`或`false`，参数`--operator.action=price-monitor-permission --operator.id=...`。变更、审计、全部会话撤销同事务，重新登录生效；创建账号不自动授予，无HTTP提权。当前登录user为id/role及十一个独立布尔位，精确13字段；客户端仍兼容已知旧形状。

进入“价格监控来源依据”，从真实当前报价来源选择READY记录；先核对门店/地区、标准项目服务内容/质检、原项目来源及报价版本。UNKNOWN表示版本或原保存凭证等不完整，应核对真实来源，不能补造审计或以示例价替代。

填写含边界上下限、计价单位、车型/服务适用说明、可追溯来源及未来北京时间窗口，勾选范围确认后保存草稿。发布前再次明确确认完整来源、区间及窗口；发布冻结，仅可停止。原报价改版或项目/适用来源改变后需重新确认并新建依据；到期发布位仍保留，先显式停止旧版再发布新依据。

配置页只管理依据，通过“只读价格比较”入口按当前读取时点核对来源/窗口/发布凭证。未知来源不判正常或违规，偏离仅需核对；完整操作见[只读比较](PRICE_COMPARISONS.md)。

网络或503导致未知结果时，重新登录当前账号并读取服务器后“重试原依据请求”，保留原正文和键。表单禁改，不能新键重建。持久存储按运营账号隔离；存储异常先核对服务器再显式清理本机未决请求，清理不删除服务器依据、不自动提交。

来源409：重新读取当前报价并确认版本，原创建回执恢复仍只用原键；401/403检查当前独立权限；停止原依据即使原门店或项目停用也可执行。原价格和订单不由本功能修改。详见[协议](../api/PRICE_MONITOR_SOURCES.md)。正式识别/短信/微信身份/资金、真机及发布仍最后R9。
