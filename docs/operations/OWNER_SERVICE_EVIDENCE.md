# R7a 使用与运维

车主登录后进入“我的订单→订单详情→查看施工进度与前后照片”。页面展示原记录时间线、六类证据和报工内容。接车图是到店施工前记录，完工图是施工后记录；可以手动各选一张前后照片进行对比；角度和数量可以不同，不能据此推断未提供的照片。对比时两张图都重新授权，以较早到期清理。缺失或未知时刷新或核对原业务记录，不补造来源。

不可用图片核对顺序：当前订单归属/会话→原记录未删除且有可信提交来源→图片与该记录/类别一致→扫描/类型/大小→原上传者。防护照片原表未冻结上传者编号，保守限定当前仍属于原门店的店长/店员文件；转店后不能据旧防护关系继续开放该文件。技师报工照片按原报工technician_id匹配，后续员工转店不改变已提交的历史归属事实。

签名仍由原私有存储服务产生，最长300秒。签名前后复核覆盖外部存储IO期间变化；已签URL的残余有效期不能承诺瞬间撤销，页面在到期/离页主动移除引用。禁止把签名URL加入消息、公开卡片或长期日志。

该步骤无迁移、无新开关或生产种子，数据库仍95表。没有扩大商家/技师写权限，也不改变付款、报工、质检、核销或归档状态。现有数据库需已应用V001–V043；不通过删卷升级。
