# R8c1b1 运营精选与引用导入操作

先迁移V057，再更新后端及微信小程序/H5；117表，无精选种子或历史授予。独立can_community_curate默认0。原EXPERIENCE_PUBLICATION_ENABLED仍控制实际经验展示与当前来源，无新正式渠道开关。

沿[离线运营管理](OPERATOR_ACCOUNTS.md)，operator-admin且web-application-type=none，显式`OPERATOR_CAN_COMMUNITY_CURATE=true`或`false`、`--operator.action=community-curate-permission --operator.id=...`。权限变更、审计及全部旧会话撤销同事务，重新登录生效；无HTTP提权，创建账号不自动授予。登录当前id/role及十二布尔位共14字段，客户端兼容已知旧形状。

进入“同款经验运营精选”，从可核验获批版本选择，核对引用编号、车型和固定事实；填写来源及排序依据（仅运营可见）、1至1000000整数优先级和未来北京时间窗口，勾选来源确认后保存草稿。优先级小值在前，同值后建立记录在前。发布前确认具体版本、来源/排序和窗口；发布冻结，只能停止。过期发布仍占唯一发布位，先停止再替换。

车主“同款施工经验”展示“运营精选（最多20条）”。没有有效配置显示暂无可核验精选，展示关闭明确未开启；不显示虚构浏览量或排名热度。来源、车型或授权变化隐藏，不自动把旧配置绑定新审核版本；运营应重新核对真实来源，保留旧快照。

车主可复制当前有效详情的应用内引用入口。接收者手动粘贴到同款页“打开收到的经验引用”，登录后选择本人车辆重新核验；输入错误明确提示，不读取任意网页或自动读取剪贴板。此入口不替代授权，不是官方微信分享或匿名公开链接。

写结果未知时保留原正文/键，通过“重试原精选请求”恢复。恢复数据按当前运营账号隔离；存储失败阻止新提交，核对服务器后才能显式清理。来源暂不可读时可以核对已有配置、停止或恢复原请求，新创建/发布须等来源恢复。401/403核对当前独立权限；409重新读取来源/版本/窗口；审计失败事务回滚，不能补造凭证。
