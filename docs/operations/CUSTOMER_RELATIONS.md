# R8b3b 本店客户关系操作

用户确认最小服务关系方案。无需新增授权位或迁移，现有本店店长身份可只读；普通员工/技师/运营不能读取汇总。正式身份/资金仍不默认开启，整个R8完成前代码和文档仅本地。

从门店入口选择“本店服务关系（店长）”，读取服务器有效本店关系列表，再进入关系下本店订单。分页固定20。界面关系编号是本店订单锚点，不是全站车主账号；更换账号不沿用原店结果，跨店或失效锚点返回404，应刷新列表。

车型缺失显示未知。最近核验接车时间缺凭证显示未知，不能以预约时间补填。身份来源未知/测试明确标识，不计作正式有效新客；服务订单数仅付后/完成状态记录，不能据此对账或确认支付成功。

详情可进入本店订单，当前有效服务工单可“重新核验本单已授权服务资料”。没有授权时原资料页仅本单必要信息；车主从本人订单选择“本单历史档案授权与撤销”，逐条授予或撤销，沿原源版本/CAS/审计协议。不新增电话、车牌、VIN、长期客户档案或跨店搜索用途。

授权撤销/记录变化/工单结束或异议后新读取被拒绝。已接收的内容不能远程抹去；页面隐藏、切号、刷新会清当前结果，旧请求不回填；原图片受原短期访问与当前权限复核约束。客户关系读接口不写授权、积分、佣金或成绩。

401重新登录本店店长，403核对真实角色，404从本店列表重新读取有效锚点；503核对数据库/来源并刷新，不把错误显示成没有客户。API见[最小服务关系](../api/CUSTOMER_RELATIONS.md)，下一步[来源价格监控](../progress/R8B3C_PRICE_MONITORING_NEXT_PLAN.md)。
