## 3. 真实环境验收

每项填「通过 / 失败 / 阻塞 / 未执行」、验证人、日期、环境版本与脱敏证据编号。不记录 `X-WX-OPENID`、`X-WX-UNIONID`、令牌与完整请求/响应体。

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| C0 | 关闭公网访问后，从公网直接请求服务任意接口 | 不可达；确认无法绕过微信网关伪造身份头 |
| C1 | 真机从车主入口进入，**不开启**开发者工具的“关闭域名校验” | 自动静默登录成功，进入首页；`POST /api/auth/cloud-login` 成功且未调用 `wx.login` |
| C2 | 同一微信身份退出后重新进入 | 复用同一车主主体，无重复账号 |
| C3 | 车主点击微信手机号授权按钮 | 获得 `phone_bound=true` 与脱敏号码；号码不以明文进入共享证据 |
| C4 | 未绑定技师进入技师入口 | 返回 `BIND_REQUIRED` 与短时绑定凭证；该凭证访问业务 GET 被拒 |
| C5 | 用有效员工码绑定后再进入 | 绑定成功并得到 TECHNICIAN 会话；重复进入复用该员工，不新建员工 |
| C6 | 用有效刷新凭证调用 `/api/auth/refresh`，再重放旧刷新凭证 | 首次轮换成功；旧刷新凭证立即被拒 |
| C7 | 退出后用旧访问与刷新凭证访问/刷新 | 均被拒；重新进入须重新走网关身份 |
| C8 | 分别用 OWNER、TECHNICIAN 会话访问非本角色受保护资源 | 服务端按实际身份拒绝，不能通过改客户端入口或归属 ID 提权 |
| C9 | 在真机走通车辆列表、档案与图片预览 | 全部接口经 `callContainer` 可用；注意图片须可达的存储直传地址（对象存储外迁属后续工作） |
| C10 | 以第二个真实微信身份复核车主数据隔离 | 看不到他人车辆与档案 |

C9 若因对象存储未外迁而失败，记录「阻塞」并关联后续工作，不得记为通过。

## 5. 回退

- 服务端：`WECHAT_CLOUD_RUN_ENABLED=false` → `/api/auth/cloud-login` 立即不存在，`/api/auth/wx-login` 不受影响。
- 小程序：清空两个 `VITE_WECHAT_CLOUD_*` 变量并重新构建，回到 `uni.request` 通道。
